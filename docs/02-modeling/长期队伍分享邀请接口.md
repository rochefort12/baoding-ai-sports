# 长期队伍分享邀请接口

2026-10-12 接续 ADR-042。源码已实现；迁移、真实普通角色验证和用户接受分别以本轮新回执为准，不改写旧邀请验收报告。

## 对客流程

当前队长在队伍详情生成或复制入队邀请链接。链接有效七天，可以撤销或更换。接收者匿名打开先看到队名；有账号则登录，没有账号则注册后登录。缺少必填本人资料时继续到档案页，保存后回到同一条邀请。资料完整后弹出队伍与本人姓名的确认表单，点击「确认加入队伍」才建立成员；关闭或「暂不加入」不写入成员。

接受队长分享授权直接加入，不再重复提交队长审批。输入队伍编号的一般申请仍由队长审批；发给已注册指定本人手机号的定向邀请仍只有受邀本人可接受。长期队伍关系不自动建立或确认任何赛事报名。

## HTTP 契约

| 接口 | 权限与行为 |
| --- | --- |
| `GET /sports/c/teams/{teamId}/share-invitation` | 平台本人齐档且为当前有效队长；返回有效分享的 id/path/expiresAt，没有有效分享时 data 为空 |
| `POST /sports/c/teams/{teamId}/share-invitation` | 同上；`{replace:false}` 创建或复用当前有效链接，`{replace:true}` 撤销旧授权后生成新授权 |
| `POST /sports/c/teams/{teamId}/share-invitation/revoke` | 当前有效队长撤销所有当前待用分享；重复撤销不改变现成员 |
| `GET /sports/public/team-invitations/{token}` | 持有 64 位十六进制随机凭据的匿名最小预览；仅 teamId/teamName/status/expiresAt，不含队内名单或个人资料 |
| `GET /sports/c/teams/share-invitations/{token}` | 平台本人齐档；在预览字段之外返回 currentMember/previouslyUsed，仅查询本人关系 |
| `POST /sports/c/teams/share-invitations/{token}/accept` | 平台本人齐档，必须 `{confirmed:true}`；有效分享原子写本人接受记录、成员、失效旧待办及队长站内信；返回 teamId/teamName/alreadyMember |

H5 路径为 `/portal/teams/join/{token}`。登录、注册、档案 `returnTo` 只保留符合该路径与 64 位凭据规范的站内目标，丢弃手机号、验证码、任意外链或管理页。不会因登录或完善资料自动接受。当前可分享的是网站链接；实际微信小程序转发与登录适配尚未由本接口证明。

## 状态和事实

复用 `asp_team_invitation`。旧记录新增 invitation_kind 默认 direct，原字段与成员不回填改写。share 行没有 target_person_id，含队长账号/稳定档案、256 位随机凭据和 expires_at。该凭据属于可转发的入队授权，数据库受控保存明文以供当前队长再次复制，不授予队内资料、报名、付款或结果权限；不写入通知、公开文档、错误或运行回执。匿名响应不回显凭据。

本人接受后另写 direct/accepted 行并关联 share_invitation_id。来源加本人唯一约束，当前有效成员重复确认返回 alreadyMember，不多写成员或通知。此前使用过同一授权的人离队或被移除后，旧链接不能重建成员，须队长重新邀请。成员变化和分享接受均在 PG 队伍行锁、现有互斥及同一事务内完成；不只依赖 Redis。

分享 pending 才可用，到期得到 expired；撤销/换链接得到 revoked；队长转让或解散使旧分享失效。查询有效性还校验授权队长稳定档案与当前有效账号，账号停止不复用旧分享授权。队伍解散保持终态。历史定向邀请的原接受规则不被分享替代。

接受分享给授权队长写 `team-joined` 最小站内信；移除长期队员给被移除本人写 `team-member-removed`。内容不含其他队员或私人报名字段，保留业务跳转与去重，短信不假定送达。

- `scripts/Test-TeamShareReturnTo.ps1`：安全回跳规范单测；2026-10-12 实际 10 项通过，私有回执在 `.local/team-invite-experience-20261012/return-to-c382b537e0024e7da29ee40cea4703c2/`。
- Java `TeamShareRulesTest` / `TeamShareServiceTest`：到期、撤销、转让、本人确认、离队重放、当前成员幂等、队长凭据权限和匿名最小披露；由本轮总构建执行。
- `scripts/Test-TeamShareMigration.ps1 -RootDirectory <明确保护目录>`：仅 exact 隔离库，先 dump/独立恢复、原字段全指纹、前向与 ledger 重放、六种约束拒绝及回滚，最后才对同一隔离库应用 V041。迁移脚本不可在已应用后盲目重跑。
- `scripts/Test-TeamShareFlow.mjs`：准备好的独立普通角色、合成队伍、匿名预览、实际注册页回跳（不发送短信）、真实网页登录与桌面/手机确认、并发幂等、移除通知、撤销/换链接。凭据和阶段成功标记留受保护 state.private.json；后续沿该状态接续，不重做成功写入。

这些自动化与模拟账号证据不能替代真实注册短信、新用户完整注册/建档、微信小程序、外部分享设备或用户当前队伍验收。正式域名与公开网络开放仍按原交付边界，不因生成 H5 链接自动改变本机暴露范围。
