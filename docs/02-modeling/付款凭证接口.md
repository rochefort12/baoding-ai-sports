# 可选付款凭证接口

依据 [ADR-027](../03-architecture/ADR-027-可选付款凭证与报名资金流程验证.md)，2026-10-10 实施。报名及义务编号沿上游 Long 字符串传输。凭证不是 `asp_payment`，没有确认到账或批准报名的副作用。

| 方法与地址 | 请求/响应 | 服务授权 |
| --- | --- | --- |
| POST `/sports/c/registrations/{registrationId}/payment-proofs` | multipart `file`，查询参数 `requestKey`；返回 ProofCard | 本人管理人或当前队长；已提交、正常赛事、收费 open 义务 |
| GET `/sports/c/registrations/{registrationId}/payment-proofs` | 当前付款义务 ProofCard 列表 | 本人管理人或当前队长 |
| GET `/sports/b/registrations/{registrationId}/payment-proofs` | 当前付款义务 ProofCard 列表 | 当前组织会话、payment 动作、所属赛事 |
| GET `/sports/c/registrations/{registrationId}/payment-proofs/{proofId}/image` | 私有图片字节，no-store | 本人管理人或当前队长；凭证必须属于该报名 |
| GET `/sports/b/registrations/{registrationId}/payment-proofs/{proofId}/image` | 私有图片字节，no-store | 当前组织 payment 动作、所属报名 |

ProofCard：`id`、`obligationId`、`fileId`、`uploadedAt`。图片 ID 不代替授权，通用 `/sports/b/media/{fileId}` 不能读取凭证。文件内容校验 JPG/PNG/WebP、每张不超过 5MB；最多五张。同键重传同内容返回已有附件，不同内容拒绝。

上传不自动声明付款。原 `POST .../{registrationId}/payment-declared` 仍独立可用，上传失败不撤销此前成功的声明。免费、草稿、撤回/拒绝或义务关闭时不能新增付款凭证。当前通过报名可以查看当次材料，重新提交生成新义务，默认列表不继承旧材料；历史附件保留在原义务引用中，单张读取仍需报名授权。

模型：`database/model/catalog.py`；迁移 V027；报名模块负责关联和身份，组织模块通过 `StoredObjectApi` 存取私有文件，财务模块的到账/净额计算不读取附件来改变资金状态。
