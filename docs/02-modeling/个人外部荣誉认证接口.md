# 个人外部荣誉认证接口

实现归属 D10 `aisports-table-honor`，公共投影 `HonorDisplayApi` 不依赖实体/Mapper。V038 为前向追加；既有赛事证明、成长积分和成长称号独立。当前入口只支持世界级赛事个人冠亚季军，由平台负责人人工核实。

| 接口 | 目的和授权 |
| --- | --- |
| `GET /sports/honors/certifications` | 本人申请，平台参赛身份、active账号 |
| `GET /sports/honors/certifications/{honorId}` | 本人或平台负责人私有详情，含最小实名归属投影和历史 |
| `GET /sports/honors/certifications/review?status=submitted` | 平台负责人审核列表，最多200项 |
| `GET /sports/honors/certifications/approved?sportId=` | 本人已通过荣誉展示投影 |
| `GET /sports/honors/certifications/public/{accountId}?sportId=` | 匿名只读；账号active，认证approved/verified且荣誉与运动名片双公开同意 |
| `POST /sports/honors/certifications/{honorId}/proof?expectedVersion=` | multipart `file`；本人可编辑状态，当前上传UI能力已开放。每份5MB图片/PDF，最多8份 |
| `GET /sports/honors/certifications/{honorId}/proof/{fileId}` | 本人/平台负责人，当前或历史确实引用、用途和文件拥有者正确；no-store、nosniff |

五个 JSON 写动作统一使用 `/sports/platform/actions/{code}/preview|confirm|execute`。输入 `honorId` 使用 Long字符串，`expectedVersion` 为整数，身份始终来自服务端。执行有稳定请求键；确认绑定内容、申请及本人档案版本。

| 动作 | 输入 | 业务边界 |
| --- | --- | --- |
| `honor.certification.save` | `honorId?`, `expectedVersion`, `detailsJson` | 新建expectedVersion=0，已有draft/correction/rejected可编辑 |
| `honor.certification.submit` | `honorId`, `expectedVersion` | 明确人工确认，至少一份本人有效私证，提交后锁定 |
| `honor.certification.review` | `honorId`, `expectedVersion`, `decision`, `reason`, `verifiedDetailsJson?`, `expectedPersonVersion?` | 仅平台负责人。decision为approve/correction/reject；approved仅允许revoke。approve必须已核对本人档案版本及正式事实；每项决定需人工确认 |
| `honor.certification.wear` | `honorId`, `expectedVersion`, `ready` boolean | 本人已通过且有效，只保留每运动一个认证佩戴 |
| `honor.certification.visibility` | `honorId`, `expectedVersion`, `publicVisible` boolean | 本人已通过且有效，公开访问还受名片开关限制 |
| `honor.certification.proof.upload` | 登记契约 `honorId`, `expectedVersion` | 实际文件从专用multipart入口提交；JSON执行拒绝伪造文件成功 |

`detailsJson`：eventYear整数，eventName完整赛事名（最多100字），sportId字符串，place整数1/2/3，level必须world，sourceUrl可空或HTTPS，proofFileIds为去重本人私证ID字符串数组。`verifiedDetailsJson`：eventYear/eventName/sportId/place/level及officialIssuer、officialResultsUrl均必填，审核责任人独立核实。`expectedPersonVersion` 为私有详情中的本人档案版本字符串，批准前服务端加锁复核。额外状态、标题、审核人等输入一律拒绝；准确称号由已确认事实生成。

详情 `applicantIdentity` 仅本人/平台负责人可读：accountId、personId、legalName、birthYear、documentType、hasIdentityDocument、profileVerificationStatus、personVersion，以及当前账号/档案状态。实际未核验的档案明确显示未核验，不因申请证明或平台审核自动变为已实名核验。审核快照保留此次本人归属。公开 `CertifiedHonor` 无实名、文件ID、理由、历史或审核人信息。

个人组件 `components/consumer/HonorCertification.vue` 无props，`changed` 只在实际办理回执后触发；平台组件 `components/business/HonorCertificationReview.vue` 无props，平台工作台 `tab=honor`。草稿切换/离开有防丢提醒，按钮防重复点击，取消确认不伪造成功，证明PDF需用户主动下载查看。认证徽章仅依据approved事实显示，不因图案或昵称授予荣誉。

实现与验证区分：单测是mock边界；脚本真实调用隔离HTTP/OSS但全部荣誉资料合成。实际世界赛事事实、真实证件核验、上线开放和外部短信均不得由本说明或合成测试推断完成。
