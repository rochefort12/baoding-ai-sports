# 录分、报到和证书业务流程

日期：2026-10-06。状态：已开发，待业务验收。依据 ADR-010。名单见 [报名业务流程](报名业务流程.md)。

目标更新见 [ADR-011](../03-architecture/ADR-011-一期业务收口与交付边界.md)，以下变更仍待实现/验收。

## 1. 谁在用

| 角色 | 本期能做 |
| --- | --- |
| 办赛人员 | 给已通过审核的人做赛事报到，手工建场次，录入或导入草稿结果，确认正式结果，确认获奖 |
| 参赛本人 | 查看所参与场次的正式赛果；获奖本人另可查看私人证明，不开放草稿和无关私人信息 |
| 队长 | 只能看自己的证明 |
| 公开页 | 不能打开证明 |

办赛人员沿用 `organize`。页面在组织工作台的「报到录分」。参赛者从身份档案进入「我的证明」。

## 2. 报到

按 2026-10-12 用户决定，一场赛事的每个项目、一个自然人分别有一次有效报到，来自本项目已通过的冻结名单。待审不可报到，不做自助报到。收费报名须满足本项目当前有效足额实收；另一项目免费或足额款不授权本项目报到。资金冲正后的限制继续办理，历史到场和场次保留，由运营协调；结束不新增正常报到，取消停止新执行。

相同请求键再次提交返回原来的项目报到；换项目或人员则拒绝。换一把请求键也不能在同一项目插入第二条有效报到。新项目报到不会阻止另一未报到项目合法整单撤回；旧未知项目记录保守阻断撤回，保留为“待项目核对”，不推断成全部项目已报到。成长仍按赛事、运动、人员计一次。迁移及历史边界见 [ADR-041](../03-architecture/ADR-041-赛事项目分别报到.md)。

## 3. 场次和结果

场次由办赛人员手工建立，两侧都是本项目已通过的报名。内部会有一条不展示的 `SYSTEM_MANUAL` 阶段，没有竞赛规则版本。

结果先是草稿。草稿可以手改，也可以用导入覆盖同一条草稿。导入格式是文本行：`matchCode,slot,outcome,summary,games`。位置是 `A` 或 `B`，胜负是 `win`、`loss` 或 `draw`。导入不直接确认。导入只在办赛人员当前选中的竞赛项目里按场次编号查找；别的项目可以有相同编号，不能写入那一场。

确认后的内容不能由普通保存或导入覆盖；责任人可通过既有赛果修订能力带版本和原因更正或撤销，旧结果保留。内容完全相同的再次提交不再插入新结果。内容不同的修改和导入都拒绝。保存草稿的请求键包含场次编号，同一把键不能改写另一场；导入内容包含赛事和项目。重新打开草稿时带回原来的双方胜负。系统不判断某一局是不是合法比分，也不根据胜负自动发奖。

## 4. 获奖和证明

办赛人员对已通过报名确认称号，须关联正式结果或承办方确认的排名依据，并记录确认人/时间。按冻结名单给本人证明、共用 award_key，退队不改旧依据；展示赛事、组织、项目、称号和日期，不冒充外部官方等级。

证明页面只给本人，以及需要核验的办赛人员。不生成文件，也没有公开地址。

本人赛果展示本人参与场次对阵、比分/摘要和胜负，双打双方各自有权，草稿不开放；取消赛事的结果/证明标历史。取消不新增录分/确认/证明，结束可处理已有场次结果及有依据证明，不新建场次；正式结果不能覆盖。

## 5. 本期不做

抽签、自动赛程、专项规则计分、完整申诉裁决及自动下轮改判、场次检录、自助报到、实际出场、公开证书。责任人的受控结果修订及相关证明复核已在本地实现，见下节。

## 2026-10-09 质量检查：结束后的执行边界

ADR-011规则不变。服务端新增报到、创建场次现在按赛事endsAt拒绝结束后的新增执行，取消限制仍优先。已有场次的结果整理、确认及有依据的证明不使用这一结束门禁。没有新增表或改变接口参数；本轮只编译/测试源码，没有重启运行包，见[第二部分报告](../04-verification/全局质量检查-第二部分-20261009.md)。


## 2026-10-12 单侧导入和手动计分交互

每场五列的一侧结果即可自动补齐互补胜负；所有总/分局比分按A:B。例如01,A,win,2:1,21:18|18:21|21:17。兼容旧双行及其镜像B比分，重复同侧、矛盾、跨项目或未知场次仍拒绝；解析后单事务写草稿，失败整批回滚。胜方点击选择，本局计分可加减/直接填，必须手动结束本局，结束比赛建议胜方后仍核对保存草稿；当前局未结束不能静默保存。默认21仅可修改的提示分，不是专项规则，也不自动结束或确认赛果。正式确认保留开赛门禁，正式更正沿用既有赛果修订而不是覆盖旧结果。见ADR-038及本轮25项普通账号报告。

## 2026-10-12 结果依赖与奖项连续记录

本地实现按 ADR-039 收口：同报名项目的一项最终名次连续办理，名称变化不再新增第二项有效名次。专项奖和跨项目奖项独立。新名次绑定整个项目的正式结果，专项奖绑定实际选择的正式场次；相关更正、撤销、新增正式赛果使依赖奖项待复核。复核展示冻结名单、项目、实际依据场次与版本；责任人选择重新签发或撤销，写入原因，核对期间赛果变化则拒绝旧依据。

旧明确中文名次及 previousHonorId 连续链兼容归并，原行不删除。重新签发撤销同一奖项旧有效行、保留撤销原因与新版本引用；本人默认仅看当前有效，历史单列且不可下载有效旧证。不按自然人跨项目合并，不自动排出名次，也不新增完整申诉/排名系统。旧未结构化依据在本人、本项目范围保守处理，含糊旧自定义称号仍需人工核实。实际执行与边界见[奖项、材料和队伍报名报告](../04-verification/奖项材料与队伍报名修复验证-20261012.md)。
