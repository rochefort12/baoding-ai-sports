# 三人联测资料

全部合成，仅供本轮隔离试用。没有预先申请组织、发布赛事、提交报名、确认收款或比赛结果。

| 文件 | 使用方法 |
| --- | --- |
| [正常赛通知](正常赛通知.txt) | A 获准入驻后粘贴到助手，先整理候选表单，再核对实际测试时间。建议日期是模拟输入，不是负责人已批准安排 |
| [通用助手提问](通用助手提问.txt) | 每次发一条，检查原文依据、草稿选择和可见处理进度 |
| [异常分支资料](异常分支资料.txt) | 正常主线后另建 X/Y/Z 赛事测试取消退款、无需审核、名额和撤回，避免破坏正常赛 |
| [批量比分样例](批量比分样例.txt) | 在当前选中项目真实存在 01—06 六个场次时使用；尚未建六场就只复制已有场次对应行。分数是模拟 A 侧结果，导入仅保存草稿，正式确认待自然开赛后 |

文字直接粘贴；不要将 `.txt` 当作当前上传组件支持的附件格式。若要测试 DOCX、PDF、图片和扫描识别，解压[现有九份资料](../办赛通知测试资料-20261012.zip)，每份用独立会话，先要求整理，检查历史日期与来源限制。该包两份官方材料是**正文摘录**，完整官方附件未取得；多页扫描包含不同赛事，不能合并成当前正常赛。

合成手机号不发送真实短信，不填现实身份证件、健康资料或银行卡。需要的本人基本信息由 A/B/C 在档案页使用模拟姓名和生日填写，D/E/F 已准备合成档案。本轮不预填他们的赛事声明或参赛名单。
