# 产品组件与视觉验证 · 2026-10-10

本轮依据用户“用自己的 JS/TS/CSS 组件化，重新设计 UI”实施。交付已接入运行中的 Vue 产品，访问 `http://127.0.0.1:5190/portal/login` 和 `/portal/home`。

## 已实现

9个自有组件：按钮、输入、卡片、状态、筛选、统计、标题、空态和球场SVG。新增共享设计变量及品牌标记；统一深绿/石白/青柠视觉，个人荣誉保留金色。参赛、主办方、政府和平台外观统一，组件实际承载表单和操作。

参赛登录、注册、找回密码使用原生输入和校验，修复首次进入未填写就报错；补齐关联错误、错误焦点、密码显隐、忙碌禁用及验证码故障重试。工作账号登录使用自有输入，保留若依校验、租户和第三方授权。登录/注册/恢复保留原任务，真实登录后返回该任务。

首页五个服务入口、键盘筛选、赛事状态与SVG封面、房间主要操作、成长主要按钮、主办方统计及政府管理卡片已接入。房间称号仍在头像上方，成长依据和展示权限沿用业务记录。手机主办方赛事采用独立操作行，避免标题被按钮挤窄。

旧样式从全局入口先装配，设计系统最后装配；移除页面重复导入，修复登录左侧区、主办方导航与统计、政府导航的覆盖冲突。复杂表格、日期、上传、弹窗及资金表单继续复用原控件，不改变权限与事务。
