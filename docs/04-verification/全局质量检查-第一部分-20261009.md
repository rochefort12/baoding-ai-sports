# 全局质量检查：第一部分基线与范围

日期：2026-10-09。执行范围为[四部分检查方案](全局质量检查方案-20261009.md)的第一部分。本轮只盘点、读取和验证现状，未修复产品代码或修改测试断言，未重启服务、修改数据库或发起真实业务写入。后续部分尚未执行。

## 结论与基线

现有前端测试包含新版正式 Vue 页面及两端 AI 助手，并非全部针对旧原型。但当前复跑已出现失败和复验差异，不能沿用历史通过结果宣称当前全量稳定，更不能用隔离页面测试证明业务事务正确。

盘点时 Git HEAD 为 `bb49f7f2f3d83eda20129ba8c5c691fae1c4bfd5`，工作区有 99 条状态记录；提交号不是当前运行版本的完整描述。相较方案初次盘点的有限指纹集合，两端助手及两个 AI 页面测试文件均有变化。本轮保留既有改动；基线文件只覆盖所列文件，不代表全仓库冻结。

盘点得到 8 个业务模块、26 个正式页面文件、24 个 Test-* 脚本文件、24 个迁移文件。页面文件数不等于路由数量；PowerShell 包装入口与对应浏览器脚本不能算成两套独立测试；迁移文件存在不表示已经在开发库应用。

运行记录中的后端、前端和网关进程均存活，5173 的 `/portal/home` 与 8080 的 `/sports/public/events` 返回 HTTP 200。此结果只证明入口可响应，不证明所有源代码已合包、身份授权正确或业务链可完成。未核对数据库实际迁移版本。

工程依据先读 [ADR-011](../03-architecture/ADR-011-一期业务收口与交付边界.md) 和[一期未完成事项](../01-development/一期未完成事项.md)，再读对应流程及后续 ADR。当前 AI 交互以 ADR-015—019 与用户最新决定补充；设计批准、管理员试验、历史模拟与普通角色验收分开记录。

## 测试分类与证据边界

Test-BusinessBackend 当前只选择资金与竞赛的部分测试；Test-InvitationBackend 只选择部分通知和队伍邀请测试。脚本名称不能替代实际执行清单。后端默认 `skipTests=true`，编译/打包成功不能据此宣称测试已执行。

部分浏览器夹具对未登记 GET 返回成功空数据，可能遮住接口变化。B 端 AI talk 夹具主要返回 update，尚未充分覆盖 CREATED、重复确认及失败恢复。这些是待核对的测试缺口，尚不能直接认定对应生产业务错误。
