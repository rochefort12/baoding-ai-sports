# 强 Agent 材料与交互验证（2026-10-12）

本轮已在原隔离演练环境实施材料读取、通用对话接续、可见处理进度和办赛表单交互。普通办赛方实际模型、接口及浏览器验证通过。用户原任务保持候选待确认，原件和第一次失败保留；只为验收生成了一份未发布、免费、带资料封面的模拟赛事草稿，没有发布赛事或新增付款。

## 已实施的行为

- 普通聊天沿用服务端意图判定。明确办赛目标进入候选准备，资料比较等通用任务继续使用原通用 Agent、MCP 授权和预算，在同一个聊天窗口接续，移除「其他任务」浮窗。
- Word 正文、原生表格单元格和 Drawing 嵌图共用来源清单。图片按原文位置、序号和 SHA256 绑定，每批最多六张；所有图片都有识别状态，已完成转写可在同一授权任务内复用。正文位置标签不再进入逐字校验正文。
- 长字段和完整引用通过来源 ID／连续范围，从已经授权读取的正文按原顺序组装。短字段只填实际短值，冲突或未说明时保留待核对。完整引用遗漏时最多一次无工具的段落索引选择，仍计入原轮次预算；不重复发送全文、不重放业务动作。
- 上传回执、页面提示作为系统观察，不覆盖用户最新目标。材料后的用户请求再次明确放入上下文，避免只给下一步提示或忽略整理要求。
- 登录态流式进度显示真实的资料读取、逐批识图、工具返回、字段核对、失败和待确认。断线仅恢复进度读取，最终回答完成后整体显示。本轮没有实现逐 token 输出，也不请求或保存隐藏思考。
- 「查看表单」打开资料与表单对照弹窗：左侧搜索原句、点选已识别短项、选择原段或划选正文、选取图片转写及封面；右侧预填基本资料、日期、项目、人数、名额、费用、规程与声明。图片实际分类为海报或照片才推荐封面，表格／二维码保留资料用途，用户可更换。
- 保存表单仅更新候选，校验版本和当前组织授权。补充文件后保留人工字段、人工项目和手选封面；确认创建仍经过原人数、名额、整单价格及声明约束。封面从本任务原文件、图片序号和哈希派生，不接受任意外部 URL。
- 字体族和共享控件／辅助文字规范集中维护；聊天正文 16px、1.75 行高。调整气泡、间距、弹窗、手机布局和选取反馈，手机原文填写控件并排排列，避免遮住识别元素；尊重减少动画设置。

## 本轮失败与修复记录

旧测试主要覆盖短文字 PDF、单段声明、Word 文字和原生表格，以及单独图片／扫描件，没有覆盖多段声明与 Word 嵌图的组合。此前普通入口通过也不能证明专用办赛入口完整；原当次模型触发的具体字段仍未观察到，不能事后猜测。

本轮真实调用中还发现上传系统回执覆盖用户目标、通用回答遗漏逐字声明、重复全文引用选择耗尽预算，以及带封面确认遗漏 asp_file 的动作读写声明。已分别修复上下文、原句范围组装／有界索引选择和具体动作声明，保留守卫。表单第一次私有图检查错误地要求 Content-Type 完全等于 image/jpeg，实际含 charset 参数；只修正检查方式。两次表单失败及通用模型失败保留，接续原候选，不再新建或重做已成功的表单修改。界面早期截图捕捉到加载中间态，最终检查等待加载结束并改善手机原文控件布局。

## 仍未验收的边界

Word 页眉／页脚、VML、文本框及其他对象，带文字层 PDF 的独立配图、低质量扫描、完整官方附件和更多格式仍未证明覆盖。视觉文字是候选，13 张都有状态不等于每个 OCR 字都已人工验证。超过 1000 段、120000 字、Word 40 个图片引用等范围明确要求拆分，不能静默截断或扩大原预算。

本轮简化流式反馈为可见阶段快照，连接规模、所有断线提交时点和真机体验尚未全面验收。主站默认运行包没有替换或启动；本地入口使用新隔离包。正式收费、收款／退款、短信、外部服务、正式发布及原一期 21／17／7 验收仍按原清单推进，不由本轮通过关闭。
