01至05为自行编写的合成材料，组织、赛事、地址和邮箱均为虚构。06、07为有明确覆盖限制的官方网页正文摘录，**不是下载成功的官方附件原件**。本机下载附件遇到HTTPS连接失败，未用网页摘要假冒完整竞赛规程。源页面为[盐田区政府通知](https://www.yantian.gov.cn/cn/zwgk/tzgg/content/post_12877259.html)和[黑龙江省体育局通知](https://tyj.hlj.gov.cn/tyj/c112436/202509/c00_31869940.shtml)。两项均为历史通知，不作为现在可报名或已经获批的赛事。

`manifest.json`冻结前七份文件的原始SHA256和预期事实；`extra-manifest.json`记录图片/扫描版与原文的关系。九份可上传文件和这两份清单装入旁边的测试资料ZIP；七份文字通知另合为一个阅读版PDF。全部原文件保留，不修改历史失败或成功任务。

推荐依次测试收费通知、免费通知、缺项补充、同时上传两份冲突通知，再测图片与扫描版。先要求整理，不创建或发布；真正保存草稿时由主办方核对当前版本、每单价格、人数名额和声明。实际验证和已修问题见[验证报告](../办赛通知真实使用验证-20261012.md)。
