## 实际发现并处理的问题

| 原问题 | 修复后行为 |
| --- | --- |
| 空项目可以发布、下架绕过已报名规则冻结、暂停组织仍可新建 | 发布必须有已配置项目；重大变化按取消原赛另建，暂停资格在兼容及统一入口同时生效 |
| AI资料价格、比赛类型或声明在草稿确认链路丢失 | 有来源的整单价、已开放类型及独立声明保留，随版本和人数由本人核对；不明价格继续补问 |
| 重复收款冲突记录保存时互锁，异常缺人工结案入口 | 释放原事务锁后独立保留失败异常；责任人核对，幂等结案，原收退款记录不变 |
| 冲正后不足额仍能新增报到 | 新报到和新场次检查当前有效资金与独立义务，历史事实不删除 |
| 撤回重提或全退款后原付款历史入口消失 | 正式历史报名保留；详情按当次义务选择，旧快照无版本按实际时间展示，不猜测回填 |
| 必填资料尚未填完时连草稿也不能保存 | 可保存未完成资料，已填值继续校验；正式提交仍强制完整资料及本人确认 |
| 付款凭证上传被动作数据范围拒绝 | 私有文件元数据纳入实际读写声明，真实上传、回放、下载和跨人拒绝已复验 |
| 队员无法从收到的任务返回本人参赛详情 | 仅本人受邀任务提供受控详情入口，不扩大管理人或资金权限 |
| 未来赛事能提前确认正式结果及发赛事奖项 | 正式结果检查赛事及已排场次的开始时间，新奖项和正常收尾检查赛事开始；取消资金收尾可在赛前完成 |
| 投诉详情404、站内通知缺少任务链接 | 政府和主办方详情可打开；资格、取消及投诉消息返回本人任务 |

| 发布中覆盖运行JAR造成服务中断 | 保留原事故及旧包恢复证据；运行JAR改用内容摘要目录，构建使用独立文件名，最终同包已安装并实际查询 |
