# 助手按钮横向交互验证

2026-10-12，Asia/Shanghai。对应用户手机截图「按钮太密集、变小并左右拖拽」的直接修改要求。本轮只调整当前办赛助手的按钮排布与手势，使用原隔离库和现有待确认候选；不重放前轮加入队伍、报名、录分、材料保存或任何模型办理。

## 当前行为

- 快捷操作和建议回复各占一行，超出时横向滑动；手机采用浏览器原生触屏滚动，桌面支持从按钮上开始鼠标拖动。
- 按钮保持完整文字、14px 字号和 36px 高度；聊天正文保持 16px。草稿查看／删除使用自然宽度的小按钮，不再在手机上铺满整行。
- 有内容在视区之外时显示边缘提示；方向键、Home／End和Tab可访问操作。拖动结束、取消、丢失捕获和窗口失焦均清理手势；拖动产生的点击在捕获阶段拦截，下一次正常点击与键盘激活保留。
- 复用共享 AssistantActionRail 组件与集中样式，沿用现有草稿查看和删除二次确认。

决定见 [ADR-043 接续](../03-architecture/ADR-043-品牌字号与聊天选择交互.md)，证据见本轮独立[机器索引](助手按钮横向交互验证-20261012.json)。
