# 队伍、赛事与材料资源

本轮使用内置 imagegen，三次独立生成后保留原图并复制到项目。最终提示词、尺寸、文件摘要与来源说明见 [资源清单](../../plus-ui/public/images/sports/experience-assets-20261012.json)。没有将界面截图、比分或个人材料发给生图工具。工具未返回实际模型标识，不能把用户口语中的“imeg2”写成已验证的模型版本。

| 场景 | 项目文件 | 用法 |
| --- | --- | --- |
| 队伍邀请和加入确认 | team-welcome-v1.png | 三位运动伙伴，透明背景，邀请页的欢迎插画 |
| 场次、比分与复核 | match-court-v1.png | 球场、双拍和羽球，赛事区小插画；动态成绩独立显示 |
| 赛事文稿 | material-notes-v1.png | 空白记录板、笔和羽球，材料标题区装饰 |

共用颜色为既有暖白、橙色和森林绿。三个 PNG 均有 alpha，图片仅作装饰，空替代文字、禁拖动、异步解码；不把状态仅编码成颜色。品牌、运动主视觉、悬浮助手、等级与奖牌继续复用既有 sports 下资源，不另造不一致的图标体系。触控操作保持清晰文字和至少 44 像素高度，窄屏比分以逐局布局展示。

三份原始生成文件分别为 exec-b70dc2ef-db3c-4759-8c75-1d1d81856d16.png、exec-23fcc2fb-6669-4697-a64a-1548b54e6669.png、exec-d1bed82d-d076-4d8e-a90b-9ca0a278cc0a.png，保留在本机 Codex generated_images 的当前会话目录。项目使用的是仓库内副本，打包时随 public/images/sports 交付，不依赖个人电脑临时路径。

这次补齐的是邀请、场次和材料的共用资源及实际接入；不表示每个全站历史页面都经过重新设计，性能、真机网络和微信小程序另验。
