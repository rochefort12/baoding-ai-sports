## 可用性与真实性

地图、路线、场地位置、日期、收费、人数、比分、比赛规则、隐私声明、告知授权和业务正文不烘焙到装饰图片。需要分享或导出的卡片可按实际授权记录生成，并保留生成时间与最新状态入口；私有证明及个人材料继续受控访问。

没有上传头像时使用昵称首字或中性图形，不以模板真人头像代替用户。已上传头像由私有媒体接口读取，公开开关与队友访问由服务端检查。段位图片的存在不表示用户已获得段位；服务端现行规则、真实成长事实与名称决定显示，历史“荣耀”仍保留原名称。

装饰图使用空替代文本、不可原生拖拽、不接收点击；真正按钮保持可访问名称、44px左右点击区域及可见键盘焦点。动态效果使用透明度和位移，减少动态效果时关闭非必要动画。暗色模式降低角落艺术透明度；表单标签、输入、错误和确认内容始终有清晰对比。

## 固定文案清理

全 `plus-ui/src` 检索口号、演示、成熟度、工程与配置说明，并按岗位用途人工判断。首页、公开赛事、房间与成长、认证及助手分别由对应模块维护；本轮补齐主办方首页、组织申请、政府与平台卡片、赛事工作区、未开放入口、默认宣传版式及网络错误提示。

删除默认宣传口号，将页面说明改成“查看报名进度、处理待办、准备赛事材料”等具体任务。移除对象列表的建设成熟度列；平台对象字段、调用渠道、权限范围和发布验收校验值属于管理岗位实际操作，继续保留。AI不可用时提示使用模板或手动编辑，不向普通用户解释服务配置。未开放入口只说明当前状态和可用入口，不写研发路线图。

固定界面的星形和菱形字符改为有明确尺寸的第二版助手图或文件、日历、通知等职责图标。普通操作图为22px，任务卡图为32px，尺寸在共享样式和图片属性双重约束，不可原生拖拽；按钮使用“准备赛事”“生成文稿”“生成封面”“找赛事”等动作文字。未知段位只显示中性圆点及原名称，不补造段位。模型回复和用户填写的文本不做字符替换。

清理不替换数据库里的模拟赛事名称、虚构测试账号、真实错误、用户输入和已保存文稿，不把模拟验证码变成短信成功。收费资格、资金冲正与退款、审核及资料冻结、结果版本、发布确认、模型授权和隐私条款等必要事实保持原意。浏览器仅做本轮受影响页面的只读布局与资源检查，完整构建和业务验证由汇总报告分别记录。
