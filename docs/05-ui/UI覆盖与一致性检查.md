## 1. 结论与核对方法

Page Map 的原 35 个逻辑编号保留，随后新增 C00、B16/B17，当前共 38 个；P04 为明确停用方案，不计缺页。八条 User Journey（J01—J08）和 13 组状态（S01—S13）均保留，旅程中出现的独立页面引用都能在地图找到，未发现定义丢失。合并承载不代表遗漏：C16 是入口，B16/B17 承载申请/结果；B09 在 B08 内，C08 在 C07 内，B05/B14 是工作区区域。

## 4. B 端元素一致性

| 元素/问题 | 检查结果及修正 | 权限/实现边界 |
| --- | --- | --- |
| 侧栏与品牌 | 原申请页浅色侧栏/横向品牌与工作台深色侧栏不同；已统一为共享 BShell 和 sidebar | 未准入只展示本人办赛服务，赛事入口为受限提示 |
| 顶栏与身份 | 原申请页独立 org-header 的高度、留白、身份入口不同；已共用 b-top | 平台账号与组织工作台上下文文字仍准确区分 |
| 顶部页面标签 | 原申请页没有；现所有 B 页共用“办赛申请、审核进度与记录、赛事运营”页面导航 | 非独立会话，不模拟完整 RuoYi 关闭/拖拽标签功能；正式复用 TagsView |
| 任务标签 | 申请/进度/版本页补 b-tabs，共用工作区标签尺寸/字重/下划线 | 申请/进度为申请任务，赛事内部标签只在选定赛事显示，避免跨作用域混用 |
| 卡片/标题/按钮/表单 | 删除重复 org 布局样式；共用 business 的卡片边距/圆角、b-page-title 和 btn；申请字段间距整理 | 步骤条、结果卡属于任务专用组件，不强行套成赛事统计卡 |
| 中等屏幕错位 | 共用 1080px 侧栏缩窄断点，标签栏与内容区对齐 | 浏览器检查 1440/1100/1024px |
| 手机侧栏 | 原工作台侧栏隐藏且无打开入口；新增共用打开/关闭与 Escape | 导航不扩大已准入权限，320/375/390px 不整页横向溢出 |
| 刷新后标签 | 原 business.js 总是回概览；路由记录页/工作区标签，刷新恢复当前任务 | 本地路由持久化不是服务器会话验证 |
| 抽屉 Escape | 原抽屉未走关闭事件；已统一转发关闭并返回焦点 | 已执行浏览器检查 |
| 文档状态数 | UI README 导读仍写“十二组”；修正为 13 组，明确最新覆盖报告 | 不用旧摘要宣称丢失状态组 |

C 端继续保持独立视觉和移动导航，不要求与 B 端侧栏一致。未开放规划预告和真实业务任务区别保留。申请和组织运营示例场景分别标明当前身份，不把静态示例工作台当成申请人未审核即获授权的证据。
