# 全局运动与成长资源 · 第二批

已接入实际 Vue 页面，不是截图界面或独立演示。共有13张新压缩位图、7个原生头像框、6个原生称号饰件。第一批品牌、登录艺术和首页艺术继续复用。

| 组别 | 页面资源 | 用途 |
| --- | --- | --- |
| 青铜、白银、黄金、铂金、钻石、星耀、王者 | ranks/*.webp，512×512透明 | 每档独立徽章。服务端成长事实决定本人段位，未达到的等级仅可预览。 |
| 同档头像框 | frames/*.svg，256视图 | 中心透明，围绕实际头像；称号和队长标识保留独立文字。 |
| 六种个人/小队称号 | titles/*.svg | 首次登场、首次完赛、赛场常客、默契初成、默契搭档、久经赛场。装饰不替代称号获得依据。 |
| 金、银、铜奖牌 | medals/*.webp，512×512透明 | 只映射精确已登记的正式奖项。未知奖项保留原名称和中性展示；不能把成长等级当冠军。 |
| 体育助手 | assistant-orb-v2.webp，256×256透明 | 羽毛球与运动轨迹的玻璃球；替换固定星形/菱形符号，导航和按钮尺寸受限，不可原生拖拽。 |
| 球场纸面/运动轨迹 | art/*.webp，1536×1024 | 表单或任务卡角落的轻艺术层，不铺在正文、错误提示和确认内容之下。 |

位图由本次内置 image_gen 生成。`assets.json` 保留每张输入描述、原图摘要、正式文件摘要、尺寸和透明通道范围；`originals/` 保留原始 PNG。工具未返回底层模型名称，不能据此认定为指定模型版本。压缩仅缩放和编码，不改绘图内容。

头像框及称号饰件为本项目原生 SVG；`identity-artwork.json` 记录正式文件摘要。没有执行或安装外部 UI 技能，也没有引入第三方图标包。

图片只承担装饰。页面仍提供真实文字、按钮、键盘焦点和业务状态。用户上传的赛事封面、头像和私有获奖证明保持现有受控接口；这批内置艺术的完成不表示运行时 AI 生图服务已经接通。
