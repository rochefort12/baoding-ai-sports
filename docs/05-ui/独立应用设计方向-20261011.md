# 独立应用设计方向与预览

状态：独立预览已获用户批准，按 [ADR-031](../03-architecture/ADR-031-独立视觉落地与办赛材料工作室.md) 进入正式项目。下文保留本预览的设计与验证边界；正式 Vue/TS 落地及真实接口验收另见 [正式产品验证](../04-verification/正式产品界面与创作功能验证-20261011.md)。组件库选型册未被采用。

## 可操作预览

[打开独立应用设计预览](http://127.0.0.1:5193/concept/index.html)。源文件在 `style-selection-20261011/concept/`，使用独立 HTML、原生 JS、自有 CSS、原生 SVG 与原生 Web Component，不安装候选 skills 或改变既有 Vue 页面。

预览覆盖 4 个视图：发现赛事、本场集结、成长与荣誉、主办方工作台。顶部明确标记展示数据与交互，不创建报名、到账、退款、通知或比赛事实。报名核对后的入口跳到独立业务演示站，不能把模拟交互提示当成实际回执。

## 设计决定

- 暖白与石墨承载信息，运动橙突出关键动作；球拍、羽球与球场使用原创 SVG，荣誉采用克制的金属色。整体品牌服务于多种运动，羽毛球场景不等于平台永久单一运动标志。
- 少量大圆角与留白建立清晰层级；减少框线，把赛事、席位、待办和金额放在各自真实任务中。字体使用本机系统字体回退，不要求安装或分发 Apple 字体。
- 桌面使用简洁顶部导航；手机使用固定底部主要任务入口与紧凑赛事条目。手机标题、金额、按钮和席位分别验证，避免单字断行和动画挤压操作区。
- 赛事详情、规则、匹配邀请、报名核对和战绩卡用原生 dialog 连续展开，支持焦点进入、Escape、关闭和回到原任务。
- 页面切换使用可用时的 View Transitions；组件使用 transform / opacity 过渡；匹配等待、邀请倒计时、准备确认、称号选择、成长进度和微量集结庆祝可感知。默认不发声音，系统减少动态效果时关闭非必要动画。
- 房主算成员，长期小队成员池与本场两个席位分开。已得称号在头像上方；正式报名、名额、实收和赛果仍遵循原业务状态，不因精致外观改变判断。

## 预览验证与边界

实际 Edge 浏览器验证覆盖桌面 1440×1000 与手机 390×844 的四个视图、筛选、详情切换、模态焦点 / Escape、邀请接受、准备、名单和费用核对、称号佩戴、标记预览卡导出、暗色及减少动态效果。预览无业务写请求；选型服务拒绝凭据及其他工作区路径。回执见 `../04-verification/demo-20261011/concept-*.json`，截图位于预览目录。

首轮视觉检查发现手机标题出现单字断行、SVG 描边图层默认填色导致奖牌黑心、赛事封面留白比例不合适；调整后重新截图与浏览器检查。另修正手机成长名片的称号行位置。首轮问题记录保留，当前截图表示修正后的状态，不将“无横向溢出”冒充视觉正确。

这是设计确认用预览，不是原生客户端安装包，不是业务界面全量改造，也不是实际赛事验收。接入正式产品前需把选定视觉与交互移入现有 Vue / TS 组件体系，并逐项绑定当前身份、权限、业务状态、后端错误与真实回执；主办方、政府和平台端继续按各自职责设计。
