## 改版判断

正式前端已接入平台认证和业务接口，但公开首页宣传区过大，登录后的页面仍以后台表格、连续说明和测试引导为主。此次重做共享视觉层和主要页面模板，沿用已有路由、会话、返回原任务、档案校验及业务 API；没有重新建设认证系统，没有修改后台模型、迁移或真实业务数据。

品牌沿用 AI运动、莲池绿和暖橙，保定城市站、城市运动插画与本地赛事信息共同体现地域。首页先展示可办理的赛事，场馆和运动生活保持次级预告，不开放虚构交易入口。通用项目筛选保留，当前无赛事的项目显示空态；羽毛球试点没有变成平台名称或固定业务导航。

## 实际验证与证据边界

- `plus-ui` 中执行 `pnpm run check`，开发构建和类型检查通过；构建存在体积大于 500 kB 的非阻断分块提示。
- PowerShell 7 执行 `scripts/Test-ConsumerUi.ps1`：77 项通过，0 浏览器脚本异常，38 张截图；1440、390、375、320 px 覆盖首页首屏、匿名入口、空表单校验、个人页面和长名称布局。
- 真实公开页面调用本机实际接口；登录后的页面使用独立浏览器上下文、虚构身份和 GET 样例，禁止业务写请求。检查历史授权拒绝、状态分离、撤回取消、取消赛事、缺收费配置及空态，没有发送任何业务写入。
- 公开页改前/改后截图通过 `scripts/Capture-ConsumerUi.mjs` 保存；个人样例截图与结果见 `.local/consumer-ui-20261007/validation/results.json`。截图是本机证据，未提交真实凭据或个人材料。
- `scripts/check-source.py` 检查架构、共享样式、文档链接和验收映射；运行结果记录于交接。

这些检查证明界面和局部交互，不证明真实登录后的整段报名、付款、队伍管理或七类普通角色验收。未改变验收状态 JSON；前轮真实接口走查证据继续有效，但不能代替本轮普通账号浏览器验收。
