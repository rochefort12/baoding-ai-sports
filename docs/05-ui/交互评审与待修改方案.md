## UI-I01：赛事管理集中与参赛者页面预览

### 现状与评价

列表在报名审核列直接切换人工/无需审核，在操作列编辑基础信息。工作区概览虽也复用这些操作，却承载为单行表格；其他配置在任务标签中。入口存在但定位不直观。“审核方式设置”和“审核某笔报名”属于不同任务，不宜混在列表中。现预览是管理数据抽屉，与参赛者详情布局不同，不足以核对最终观感。

### 已确认方案

| 区域 | 修改方案 |
| --- | --- |
| 赛事列表 B01 | 保留查找、状态、新建；名称和主要操作进入工作区。移除直接切换审核方式，单场编辑进入工作区 |
| 工作区顶部 B03 | 常驻“预览参赛者页面”；已发布时另提供“打开公开页面”，任何任务均可访问 |
| 概览 → 基础信息 B04 | 展示名称、时间、地点、联系人等，旁边直接放“编辑基础信息”，取消单行操作表格 |
| 报名设置 | 集中截止时间、人工/无需审核及赛事采集字段等入口。截止时间仍沿基础信息保存契约，同字段只有一个编辑来源 |
| 报名名单 B07/B08 | 专门查看名单、办理资格审核、核对资金，不混放赛事审核方式开关 |
| 发布管理 B05 | 集中首次发布、恢复、下架、取消；概览只显示状态及跳转，不重复完整操作表格 |
| 列表预览 | 可保留次要快捷入口，复用同一预览能力；统一实施时评估密度 |

项目与费用、报到、场次录分、获奖证明和通知继续分区。组织字段目录仍属组织级，报名设置只维护当前赛事选用。

### 预览要求与业务边界

1. 复用 C02 详情的展示组件，核对封面、介绍、说明图片、项目、整单报价和联系人。
2. 草稿/下架通过组织授权读取，不临时发布、不放宽公开接口。标明“仅内部预览”，只读，不报名、不占位、不付款。
3. 展示已保存内容；未保存时提示先保存核对。已发布提供真实公开页链接。
4. 价格未知不标免费；收款码仍仅在授权付款页显示，不因预览公开。
5. 首次正式提交后审核方式与字段配置锁定，全部撤回不解锁。集中入口不放宽编辑、时间、组织及资金权限。

### 实施验收

- 进入单场后无需返回列表即可找到编辑、报名设置、发布和预览。
- 上下文、顶部页面标签、任务切换、刷新和前进后退一致。
- 原 `task=fields` 深链安全转到报名设置对应区域，B14 任务不丢失。
- 手机预览可达，按钮不溢出；加载失败、无权限、对象不存在、锁定原因均明确。
- 草稿预览不能匿名访问，不产生写入；同步地图、旅程和验证后才标“已实施”，业务验收独立登记。
