## 页面与可操作内容

| 页面 | 路由 | 可体验内容 |
| --- | --- | --- |
| 发现 | `#discover` | 通用运动首屏、AI常用指令、规则推荐、下一步伙伴任务 |
| 赛事列表 | `#events` | 名称搜索、城市/状态/收藏筛选、空结果恢复 |
| 赛事详情 | `#event/autumn` / `#event/weekend` | 面包屑、项目、整单费用、规程、收藏、建立本地草稿 |
| 我的参赛 | `#participation` | 固定示例任务、本浏览器新增草稿、查看及删除 |
| 我的偏好 | `#profile` | 城市、自评水平、收藏及草稿数量、本地保存与重置 |

聊天窗读取当前 hash 路由和选中赛事，回复时不切页；用户点「查看赛事」「我的参赛」等导航按钮才切换。桌面支持标题拖动、放大/还原，手机为自适应聊天窗。快捷指令常驻，规程解读显示演示规则编号及原文。回复是按关键词选择的本地示例，不是真实模型或检索服务。

报名仅保存草稿，需勾选已阅读示例规则，拒绝相同项目重复草稿；不提交正式申请。双打仍需伙伴本人确认，邀请按钮只展示/复制说明，不生成真实链接、不发送。收藏、偏好、草稿保存在独立 localStorage 命名空间。资金规则展示保留正式提交后可付款、收费实际足额后可通过、免费无付款等 ADR-011 口径；不是资金业务实现。

## 视觉与后续能力

采用 D 的二维印刷质感多运动插画，青绿/深蓝/冷白与少量暖色，左侧渐隐保证标题阅读。AI 命令卡和聊天窗置于内容背景上，使用局部背景模糊；正文实底。赛事封面使用项目自有 SVG 场地图形，与主视觉风格协调，不冒充赛事照片。

手机以单列重新组织信息，个人下一步优先于赛事发现；AI 常驻底部导航，避免浮标盖住邀请按钮。320px 收为单列赛事卡，390px 双列。竞技段位/XP、陌生人动态/私信、交通报价/酒店预订、本地商业入口暂隐藏；自评、已有关系邀请、赛事推荐保留。

## 独立插画素材

使用内置 image_gen，以已暂定的 D 桌面稿为参考生成纯插画资产。最终保存 [community-sports-hero.png](../prototype/assets/community-sports-hero.png)，默认工具原图保留。此文件是生成插画，不是真实摄影；主标题、导航、按钮等均由 HTML 绘制。

实际提示词：

```text
Use case: illustration-story. Asset type: standalone responsive website hero artwork, NOT a UI screenshot. Reference image: the approved D desktop homepage screenshot. Recreate ONLY its wide flat screen-printed multi-sport illustration as a clean separate background image, removing ALL website navigation, text, logos, command cards, event cards, buttons and any interface. Retain the reference's mature editorial illustration language, textured printed-paper feel, navy/teal/cream/pale cyan palette with restrained coral, ordinary adult jogger, cyclist, basketball participant and older adult stretching, diverse inclusive community park life. Wide horizontal composition roughly 2:1. The figures occupy the right two-thirds; left third is pale near-white blue with understated trees and ample negative space for separately coded text. Keep enough breathing room above and around each figure and avoid cropping heads or feet. One coherent 2D ink illustration, no photo, no 3D, no glossy AI aesthetic, no small unrelated vignettes, no text of any kind, no fake real-world venue/government branding. The result must work as a full-width desktop background and as a right-biased mobile art crop with readable left text area handled in CSS.
```
