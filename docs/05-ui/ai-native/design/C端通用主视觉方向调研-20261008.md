# C端通用主视觉方向调研

日期：2026-10-08。设计建议，未确认具体新稿。本轮联网查找官方品牌、设计机构与奖项案例；未生成新图，未替换正式代码或已有概念文件。

## 用户修正

现有写实人物、场馆方案过度精致，容易呈现 AI 生成质感；平台未来覆盖多种比赛，首页默认主视觉不能固定为羽毛球。已认可的版式、青绿/冷白体系、左侧渐隐和 AI 入口保留。以后主视觉可配置，本轮先确定通用底稿。

## 来源与评价依据

1. [Designing Paris 2024 — D&AD](https://www.dandad.org/work/d-ad-awards-archive/designing-paris-2024)：2025 年作品获 Black Pencil；奖项页说明其从城市街景出发建立模块化视觉系统。借鉴统一语法、几何图形与多场景适配，不照搬奥运标识或断言其网站体验获奖。
2. [Paris was a party — Conran](https://www.conrandesigngroup.com/thinking/paris-was-a-party-and-everyone-was-welcome/)：设计方说明开放、包容的理念，视觉模块可供不同场地和参与方组合。
3. [Decathlon — Wolff Olins](https://www.wolffolins.com/work/decathlon)：设计方说明品牌面向不同年龄、水平和动机的人群，统一运动感和品牌系统适配多个运动项目。其官方设计说明是方法参考，本轮没有查证此案例获具体奖项。
4. [This Girl Can — Sport England](https://www.sportengland.org/news/this-girl-can-returns-to-our-screens)：官方强调真实运动参与者和自然的运动状态。
5. [This Girl Can — D&AD](https://www.dandad.org/work/d-ad-awards-archive/this-girl-can)：相关作品有 Wood Pencil 记录。用于真实参与者与公共服务传播思路参考，不照搬聚焦女性的受众设定。

## 提案

| 方案 | 首页右侧主视觉 | 适用性与取舍 |
| --- | --- | --- |
| A 运动轨迹品牌图形（建议默认） | 少量平面曲线、弧线、轨迹与半透明色块，借运动场地和运动路径的节奏组成独立品牌图形；右侧丰富，左侧渐隐 | 不依赖球种、人脸或特定城市；易做移动/桌面适配和配置。需要原创构图与节奏，避免廉价通用渐变、粒子、霓虹和立体塑料感 |
| B 真实多项目摄影拼贴 | 两至三张真实纪实照片，以不同运动/年龄参与者局部动作组成编辑式拼贴；不修成商业模特海报 | 真实、有温度、运动含义直接；需要可用摄影素材与统一裁切、色彩，避免跨运动拼接成虚构现场 |
| C 城市公共运动生活 | 真实城市公园、公共步道或综合运动空间远景，人物小、光线日常、城市生活为主体 | 与公共服务和未来出行/本地生活衔接自然；若素材或地标不真实就不冒称保定，避免变成房产/文旅宣传画 |
| D 多运动平面插画 | 原创二维人物动作、场地片段或小幅运动图形，采用固定线宽/纸感/平面配色，避开超写实与3D | 易统一多项目和包容性；插画风格需匹配平台的可信度，避免幼儿化或堆满运动图标 |

建议默认 A；有优质真实供给时用 B/C 作为活动或地域专题。不是给照片再加颗粒、柔化就能解决问题，应调整素材语言。D 可作为视觉更鲜明的备用方向。

## 不仅是图片

首页主标题建议从只暗示球类的“打出你的精彩”改为“下一场，开启你的精彩”；示例 AI 提问可变为“这个周末，保定有哪些适合我的比赛？”。泛运动品牌定位不等于虚构已开放项目，赛事列表仍按真实开放项目显示。

后续配置可保留默认/活动素材、桌面与移动裁切焦点、渐隐遮罩、显示期限、文案及来源记录；主视觉配置不改变赛事报名规则。当前仅提出结构，不建设完整运营配置系统。

本轮未要求或生成成品新图；等方向确定再出图比较。所有研究结论与实际功能/验收状态分开。
