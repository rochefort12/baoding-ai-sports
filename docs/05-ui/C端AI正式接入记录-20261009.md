# C端AI正式接入记录

日期：2026-10-09。用户要求将已确认原型替换正式 C 端。依据 [ADR-018](../03-architecture/ADR-018-C端AI发现与公开参赛咨询.md)；业务最终依据 ADR-011。

正式入口：[发现](http://127.0.0.1:5173/portal/home)、[赛事](http://127.0.0.1:5173/public/events)。5192 的 `consumer.html` 继续是独立模拟原型。

## 实际替换

- ConsumerShell 品牌与冷白/青蓝/深蓝主题统一；共用样式位于 `consumer.scss` 与 `consumer-ai.scss`。既有报名、资料、邀请、队伍、通知、赛果和证明页面继承新主题，实际表单与权限校验保留。
- 首页使用 D 通用社区运动插画，保留左侧渐弱与局部玻璃卡。2026-10-09 起，首页左侧改为发现赛事、我的报名、我的队伍、赛果证明；桌面用右侧悬浮球打开助手，手机底栏保留 AI 助手。当前没有独立助手页。桌面是赛事流＋本人任务侧栏，手机把本人任务放到赛事流前面。访客没有伪造报名任务。
- 公开列表支持来自真实数据的运动项目、名称与阶段筛选，详情有 AI 解读入口并保留规程原文、真实项目收费及手动报名；登录回跳继续保留 eventId/unitId。
- 原有认证页复用同一插画与配色；段位、陌生人社交、出行和生活预告不占首页，旧规划路由仅保留兼容，不声称开放。
- 全局参赛助手可拖动/放大/还原；只读模型请求同意后才发送、支持失败重试、提供来源卡片与读取范围/时间。聊天不自动导航，不执行模型 HTML；“我的下一步”直接读取本人进度，不发私人数据到模型。
- 插画资产从已确认原型复制到 `plus-ui/src/assets/images/community-sports-hero.png`，生成来源/提示见 [原型说明](ai-native/design/C端AI原生HTML原型-20261009.md)。真实赛事仍优先显示组织上传的宣传图。
- 开发工具浮标默认关闭，避免遮住手机中间 AI 入口；需要时以 `VITE_APP_DEVTOOLS=true` 显式开启，正式构建不加载它。

## 接口

新增匿名只读 `POST /sports/public/ai/assistant`。请求/来源/限流/模型边界见 ADR-018 和 ConsumerAssistantController。调用复用现有网关，没有新增数据库迁移或更改报名资金事务。个人下一步复用 `/sports/c/registrations` 和 `/received`；手动办理继续走原页面。
