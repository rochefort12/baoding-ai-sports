# B端 AI 工作台正式接入记录

日期：2026-10-09。用户授权：根据已确认 AI 原型替换正式 B 端，后端接口不满足时直接补齐。设计决定见 [ADR-016](../03-architecture/ADR-016-AI办赛工作台与运营助手接入.md)。旧 HTML 及新的 AI 原型仍分别保留，正式实现位于 plus-ui。

## 当前实际实现

- 组织运营首页替换为 Fluent 方向的 AI 办赛主入口、真实赛事列表、四项运营指标、近七日提交趋势和可进入报名办理的待办卡片。没有加入虚构营收、到场率或 AI 推荐风险分数。
- 统一框架隐藏页面标签，侧栏补回报名管理与现场执行，嵌套赛事页有赛事名称及当前任务面包屑。平台管理员继续使用原生 RuoYi。
- 顶部、首页、赛事管理与助手常驻 AI 办赛入口；手动创建保留原表单与接口。全局手动保存防止连续点击重复请求。
- 助手在左侧浮窗打开，窗口/气泡可移动，支持键盘方向键、放大及还原；聊天读取路由与赛事，聊天和保存不自动导航。
- 内嵌资料办赛复用已有任务，补充文字启动。跨路由不丢任务，刷新仅用当前账号/组织的任务编号恢复，已创建后可再办新赛事。运营模式与办赛模式分别使用各自输入区，避免同时出现两个聊天输入。
- 运营分析/推广草稿调用真实模型，只读回答并标明统计更新时间；设置修改使用现有授权 GET/PUT 赛事接口，其他字段不丢失。切换页面立即收起旧设置。新增上海日期控件回填，避免 API 返回 UTC 时被误改八小时。
- 数据组件展示真实统计，通过无脚本 iframe 和 CSP 限制资源；不执行模型生成的 HTML。
- 共享视觉在 plus-ui/src/assets/styles/business-ai.scss，沿用 Element Plus 和已有依赖。资料页复用原组件，无新前端框架。

## 接口契约

| 接口 | 输入/输出与边界 |
| --- | --- |
| GET /sports/b/operations/summary | 当前组织刷新时间与逐赛事标量统计，包含赛事名称/项目/阶段；不接受组织编号，无成员资料或资金明细 |
| POST /sports/b/ai/tasks/text | consent=true；建立无文件候选任务，响应与原任务查询一致；后续 talk/确认复用原校验和事务 |
| POST /sports/b/ai/assistant | message≤2000、可选 eventId、consent、page≤300、history≤6条且每条≤2000；page/history 只是模型上下文，不参与授权；返回纯文本 reply 和 refreshedAt |
| GET /sports/b/events/:id、PUT /sports/b/events/:id | 复用既有当前组织授权查询和设置更新，发布/取消及材料锁定规则保持有效 |

RegistrationOperationsApi 放在纯契约模块；实现位于报名模块，通过 FeeApi 读当前义务状态。赛事模块不导入报名/资金 Mapper 或实体。无数据模型及迁移变更。

## 接续：十项助手反馈实施

见[ADR-020](../03-architecture/ADR-020-AI助手目标分流与草稿就绪反馈.md)。新增POST /sports/b/ai/assistant/route：eventId/taskId/message/consent/history，返回intent（operations/draft/new/clarify）；服务器验证当前赛事归属，不执行创建。原运营查询增加服务端currentTime/timeZone和实际赛事readiness；候选proposal增加readiness（canSaveDraft/blockingIssues/nextStep/checkedAt）。宣传响应新增eventName，保证名称与业务事实一致。其他原创建/确认/权限边界保持。

独立折叠候选、下一步提示、安全Markdown、放大外部点击保护及受众/三套宣传版式已实施。最终B端69项严格隔离UI通过，含实际PNG/PDF导出；后端全量134项、最终定向27项、网关与夹具21项、前端构建/类型通过。实际模型仅合成小样本，真实普通办赛闭环、跨项目加项计价及设备验证仍待接续；详见交接。

## 接续：多项目主视觉与固定文字排版

见[ADR-021](../03-architecture/ADR-021-多项目宣传主视觉与文字隔离.md)。新增POST /sports/b/events/{eventId}/promotion/visual，提交consent/style/audience/keywords；名称、运动项目来自服务端当前赛事，不能由客户端指定其他赛事事实。PromotionView新增projectName/imageEnabled/visualFileId/visualStyle/visualStale。无图像配置隐藏专用入口，生成文案仍可用已有图片或通用素材。图像失败保留原材料，相同请求复用；名称/项目变化不再采用旧主视觉。图片仅用于宣传，不覆盖公开封面。

海报取消固定羽毛球器材图，主视觉与不透明文字区分开；按实际字体换行扩展画布，保留二维码独立区域。自动选择视觉语气，手动换版式不立即调用付费图像服务。最终隔离UI72项通过，含复杂高对比背景、长标题/十二项费用、主视觉请求及PNG/PDF导出；真生图供应商仍未配置，普通角色/多项目图像质量等按交接接续。
