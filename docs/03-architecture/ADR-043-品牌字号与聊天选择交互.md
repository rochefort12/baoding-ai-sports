# ADR-043 品牌字号与聊天选择交互

日期：2026-10-12。依据：用户本轮三张截图及随后左右对齐、登录静默的直接修改决定。状态：本地实施与界面验证完成，见[独立验证记录](../04-verification/队伍邀请场次与体验修复验证-20261012.md)。

## 品牌和阅读

当前产品可见品牌统一为「AI体育」，英文为 AI SPORTS。城市、组织名称、真实赛事名称、原始资料与历史文档保留原事实；不把品牌变更当作地域或业务数据变更。证明图片保存副本的页眉使用当前产品品牌，既有已签发事实不被重写。

字体在共享样式维护正文、辅助信息、控件与标题层级。主要正文以 16px 为基础，手机保持可读字号；辅助信息与操作不继续使用旧版 9—12px 的密集规格。实心主操作采用深橙色，改善正常字号白字的对比，装饰品牌色保留。字号变化必须同时检查窄屏折行、表格独立滚动、按钮可触达及弹窗正文与底部按钮，不用整页缩放替代布局。

## 聊天过程

查看表单和删除草稿进入当前办赛任务的聊天行动卡，跟随该任务的相关回复，避免固定在窗口顶部占用阅读空间。缺项和下一步摘要靠近输入区按需展开，仍可查看完整条件；查看或编辑仍使用当前草稿表单，删除仍需明确二次确认。普通运营回答不能误显示另一办赛任务的草稿操作。

左侧固定赛事助手推广卡移除。全端复用现有悬浮静态图标，图标本身不加文字标签。独立介绍气泡使用亲切文案间歇轮换：首次约 1.8 秒出现，展示约 6.5 秒、间隔约 16 秒；手动关闭后暂缓 60 秒。用户可选择「本次登录不再提示」：当前标签页 sessionStorage 只保存布尔偏好，刷新、页面切换和组织会话切换保持静默，成功退出或重新登录才清除；不保存身份或 Token。提示可直接打开聊天。聊天、业务弹窗、拖动和后台页面期间收起提示；保留原图标拖动、键盘移动与坐标偏好。介绍文案由界面维护，不调用模型、不自动办理业务；尊重减少动效偏好，不持续播报提示。

## 首页空间

首页主视觉与右侧两张卡片在桌面使用 560px 区域，上下齐边；手机恢复正常流布局，避免右侧待办内容把图片区域无限撑高。保留当前赛事、个人报名进度和操作，调整桌面和手机排布；正文增大后不能通过隐藏重要状态换取紧凑。

本轮只更改界面与品牌展示，不调整服务器业务权限、资金或正式结果。实际浏览器、构建和截图证据见后续独立验证记录；微信、真机软键盘、全站所有历史页面和现实赛事接受仍须分别记录。

## 2026-10-12 接续：助手按钮横向操作

依据用户随后手机截图的直接决定，快捷操作与建议回复各保留单行，超出可用宽度时横向滑动；桌面支持从按钮开始鼠标拖动。使用共享 AssistantActionRail 组件和集中样式，完整文字不截断，保留 14px 字号与 36px 按钮高度，通过缩小间距和内边距节省空间。草稿查看／删除使用自然宽度的紧凑按钮，手机不再铺满整行。聊天正文保持原可读字号。

触屏保留原生滚动和缩放；鼠标达到横向阈值才接管拖动，拖动结束、取消或丢失捕获后拦截该次指针点击，新的点击和键盘激活正常办理。操作条可用方向键、Home／End滚动，原按钮Tab顺序和禁用状态保留；边缘提示仅作可滚动标识。沿用原聊天任务、查看表单和删除确认逻辑。本次接受使用新的[横向操作验证](../04-verification/助手按钮横向交互验证-20261012.md)，不改写上一轮冻结索引或重放已成功办理的数据。

## 2026-10-12 接续：三人同 Wi-Fi 试用

手机管理入口接续：消费页头部提供“切换入口”，本人资料提供“平台／政府管理”，不再依赖手机隐藏的页脚。明确切工作账号先注销当前会话再打开工作登录，避免已认证路由守卫回跳；失败不强行导航。480px以下收起重复登录与城市信息，菜单保留登录、办赛、资料和管理用途。服务端仍核验工作账号、角色及范围。实际LAN导航与未执行的真人边界见[手机管理入口验证](../04-verification/手机管理入口修复-20261012.md)。

用户确认三台设备在同一 Wi-Fi，准备各自模拟账号并逐条测试。新增内网前端5193代理同一隔离后台，保留原本机5192；账号准备与人工业务接受分开记录。普通内网HTTP缺少Web Crypto的subtle能力，动作和文稿保存的重试摘要使用既有锁定CryptoJS的SHA-256兼容实现，保持相同字节、相同摘要和相同失败重试键；成功后仍清除重试键。助手会话键直接使用共用UUID生成方法。身份、确认、金额及正式结果权限不改变，不将兼容修复当作业务完成。证据见[三人联测准备](../04-verification/三人联测准备-20261012.md)。
