# ADR-042 队伍分享邀请与参赛办理体验

日期：2026-10-12。依据：用户本轮六项修复要求。状态：本地实施与隔离普通角色验证完成；[验证记录](../04-verification/队伍邀请场次与体验修复验证-20261012.md)与真实微信、短信或赛事验收分别记录。

## 邀请与本人确认

长期队伍复用既有邀请事实，区分发给确定人员的邀请与队长主动创建的分享邀请。分享链接是有限期的随机业务凭据；队长可复制、撤销或更换，公开预览只显示队名、有效性与期限，不展示成员个人信息。链接打开后保留受控站内回跳：登录或注册、本人档案完整后仍须查看队伍并点击确认加入，不能在登录或完善资料时自动加入。分享由当时队长发出；过期、撤销、解散及队长变更后不能加入。本人退出或被移除后重放原分享不能恢复成员关系。事务锁定队伍及接受来源，防并发重复加入和越权操作。

当前交付为可复制的网页链接与上述页面流程。微信小程序可以接续同一邀请上下文和服务端确认契约，但真实小程序登录、转发与真机返回不由网页测试替代。

多人赛事报名邀请显示有权操作名单时已选账号的姓名、手机尾号与成员状态，复制前再次显示受邀对象。定向邀请仅该账号本人接受，不能因为分享了链接而替代其资料与声明。首次邀请投递完成后返回实际状态；历史未投递邀请提供明确补发操作，同版本重复不增加消息。移除成员通知本人，跳到仍有权访问的报名列表；长期队伍加入与移除使用已存在的本人站内信。通知不包含证件、健康信息或分享凭据，不冒充外部短信送达。

## 场次、奖项与材料

场次编号在项目内解释，列表、筛选及详情均显示项目。修改安排载入已有场地、起止时间，用已有上海业务时间转换，不清空原值。参赛安排随正常页面流布局，避免浮动卡片覆盖正文。

比分以可访问的动态组件展示：双方名称、总比分、胜负以及逐局分数；原字符串仍保留为数据依据。复核页用实际人员、项目、最新赛果和办理动作说明，技术修订号与历史记录按需展开，手机弹窗正文可滚动且按钮不遮住内容。正式赛果、奖项确认、撤销及证明历史规则沿用 ADR-039，不借视觉调整自动计算名次或签发证明。

材料默认阅读，手机生成工具按需展开，标题、表格、列表与代码遵循同一字体和宽度体系。表格在独立容器内横向滚动，文稿源不被渲染改写。禁止执行材料中的 HTML、脚本及不安全链接。安全测试专用输入只在未保存编辑区或测试中使用；正常试用样例不保存脚本测试字符串，不删除真实用户原文及历史。

## 资源与交付

使用内置 imagegen 生成独立原创队伍、场次与材料插画，保存项目资源、提示词及摘要。实际比分、表单、状态与操作继续由页面组件呈现。共用样式集中于 assets/styles，悬浮助手复用既有图标；用户后续直接决定的 AI体育 品牌、字体、聊天选择与首页空间按 ADR-043 实施。新迁移前必须备份、独立恢复、前向与重复验证，不重写已应用迁移；构建、运行、普通账号实际办理和目视截图分层记录。旧失败与旧验证索引保持原字节。
