# ADR-026 AI宣传工作室与渐进调整

日期：2026-10-10。依据：用户反馈宣传选项过多，无法理解生图海报入口，要求整体UI设计且体现AI原生。本决定接续ADR-017/021/022，替代ADR-022最后一节的四个常驻来源、默认仅文案与生图开关界面。打开即用的当前事实基础文案、数字格式修复及清晰错误提示由[ADR-028](ADR-028-赛事统一收款与打开即用宣传文案.md)继续接续；打开不会自动调用付费外部模型。

设计确认：用户查看桌面/手机实际样例截图后明确回复“效果很好，请按照这版生成”，确认本版为正式界面。正式Vue已接入，不再另起原型方案；真实赛事宣传生成仍由办赛人在对应赛事内操作。

## 任务与信息层级

默认任务是做一份可使用的宣传材料。界面以画布和创作意图为中心：读取当前赛事事实并预览；输入想要的效果（选填）；明确授权后点击“AI生成海报”。图像服务可用时依次调用既有生图、文案接口，背景底色适配、标题/赛事信息/二维码依既有画布排版；海报、朋友圈配图、群消息通过三个标签切换。不要求用户理解主视觉、背景材料和各生成接口。

宽度足够时左侧画布、右侧AI创作区；抽屉扩至最多1000px，保留24px外部可点区域。小助手内上下排列；手机宽度优先显示创作区，让主要入口可见。三种灵感只填入自然描述和方向，不自动调用模型。更多调整默认折叠，内含画面风格、主要读者、预览背景和只生成图片/文案；精细能力保留，主流程不用选择这些字段。

## 状态与既有边界

- 首次默认插画明确标“版式预览”，读取和预览不生成。未公开、事实变更、图像不可用、读取失败分别说明；加载失败可重试。图像服务不可用时主入口明确为AI生成文案，不假装生图。
- 请求开始固定本轮描述、风格、读者，显示真实图片/文案/排版步骤；生成中禁重复请求和修改输入。切换赛事和组件卸载通过代次丢弃旧响应，重置授权与本地选项，不让旧响应覆盖新赛事。
- 图片失败不继续请求文案，旧预览保留；图片成功但文案失败明确部分完成，可单独补文案，避免再次生图。图像/文案请求继续保留既有后台缓存复用、授权、同意、限频、组织隔离和文件生命周期边界。
- 用户明确勾选使用必要赛事信息的授权仍必需；不因新布局自动授权。预览换风格/素材不自动生成，只有明确点击生成触发请求，提示可能的模型费用。
- 不新增图像模型、在线发布、外发消息、完整素材管理或多轮图像编辑能力；自然描述用于新一轮生成，不声称精确编辑既有图片。二维码/取消状态/费用事实、独立文字区及PNG/PDF沿既有规则。

## 实现与验证

正式PromotionBoard同时用于赛事抽屉和AI助手，样式集中business-ai.scss。标签具有选中状态及键盘方向/Home/End操作；手机授权文案换行。打印窗口修正原noopener导致无法取得窗口的路径，下载仍保留异步对象URL释放。

91项B端严格隔离回归与16项宣传定向检查通过，包含生图→文案顺序、失败保留、部分完成补文案、无图服务回退、手机无横向溢出、剪贴板、PNG/PDF和绘图取色。类型检查与build:dev通过，既有大分块提示仍在。截图使用合成赛事和隔离图片接口，不是本轮真实生图证明；普通角色真实供应商/存储/取色/下载链路继续待验。详见[设计与验证记录](../05-ui/ai-native/promotion-studio/README.md)。
