# ADR-029：表模块、智能体与羽毛球一期闭环

日期：2026-10-10。状态：用户批准，实施中。依据为本次用户确认的完整实施计划；优先于 ADR-001、ADR-008 中与之冲突的旧模块划分和一期展示范围。原始母版不改写。

## 决定

体育业务一表一 Maven 工程，按模型 D01—D13 分组；统一 Java 17 / RuoYi 5.6.2 应用装配，不改变 public.asp_* 表名、历史主键、金额与名单快照。表工程仅依赖平台 core，不能依赖其他表工程或平台实现。若依身份、菜单与基础模块沿用框架结构。

入口表工程持有完整业务动作和本动作私有的跨表投影，声明读写范围，单个数据库事务处理完整链路。私有投影不是其他表工程的公共实体或 Mapper。公共 API 保持无持久化依赖；框架开户通过 API 适配。

统一 registry/authz/executor/MCP 管理能力版本、渠道、身份范围、幂等与回执。生成区与手写区分离。未建表或未完成验收的能力保持关闭。生成的目录和模块数量不表示业务完成。

一期交付组织准入及暂停恢复、人工办赛、长期队伍和本场房间、招募与自动匹配、本人报名确认、人工实际收退款、现场与赛果修订、私有证明、投诉及通知收尾。比赛结束、资金结清、投诉关闭分别判断。

个人与小队按运动记录成长。真实报到 +10、有效完赛 +30，个人同一赛事各一次；代表长期队伍有效完赛 +40，每队每赛事一次。段位阈值 0/40/120/400/1000/2400/4800。称号头像上方展示，用户选择佩戴与对外公开；成长与赛事奖项分开、来源可查、更正可追溯。

主模型及图像识别使用 deepseek-flash，宣传图片沿用 Seedream。保留独立 Node 运行进程；平台签发身份、能力与范围，运行时不直连数据库。只记录可见目标、输入、确认、工具回执和用量，不请求或保存隐藏思考。材料授权标明实际供应商，旧百炼授权不解释为 DeepSeek 授权。

## 发布与验证

V001—V029 已应用迁移不变，V030 起新增迁移。旧接口保持适配，单一业务写入口。真实普通角色、实际模型、手机和桌面验证分别留证；模拟资金与模型结果不作为真实外部闭环。先本机受控验证，不自动扩大网络暴露或推送远端。

## 2026-10-10 实施接续与产品界面

121个表工程与公共底座已装配，118张业务表已应用V030—V033，三张历史属性目录仍待建设。表模块不相互依赖，重复生成无差异。已验证的兼容动作进入事务执行器；旧跨表声明较宽，尚未全量开启无动作上下文写入拦截，不能解释为所有写入口已经封闭。

用户新增要求是成熟产品界面，按角色职能和实时任务呈现，移除PPT式口号。参赛端以赛事、房间、报名、成长和赛果办理；主办方以待办、报名详情和赛后责任办理；政府按指定审核和授权范围办理；平台以对象、能力开放、责任分配和规则管理。称号、边框、队伍归属与升级反馈保留，但不伪造奖励或就绪状态。

通用助手的材料从服务端私有存储进入有界提取与多模态请求，位置、覆盖范围和摘要留痕，当前身份在调用模型前重新核验。源文本只是材料；不注入系统权限。无密钥的故障保留、真实MCP身份和工具边界已验证，真实模型渠道仍关闭。验证与限制见[本机验证](../04-verification/羽毛球一期闭环本机验证-20261010.md)。
