# ADR-039：赛事奖项连续记录与材料阅读预览

日期：2026-10-12。依据：用户第 5、6 项修复要求；接续 ADR-011、ADR-029 和 ADR-038。本地验证记录单独保存，不以设计记录代替验收。

## 问题

原赛果更正按参赛报名批量暂停所有有效奖项，未检查获奖依据；授奖按名称找旧记录，改名次会新建另一个 award_key。复核又按 award_key 分组，旧名次重复进入待办，且 min(id) / max(version) 不一定来自同一行。原重新签发只检查该报名是否存在任意有效赛果，沿用旧依据。参赛端仅按 verified 查询，因而展示了新旧两项。

赛事材料已经有 Markdown 解析入口，但默认展示原文编辑，生成稿和已保存稿容易被误认为没有渲染；阅读预览缺少文稿的标题层级和表格样式。

## 决定

1. 同一个报名项目的最终名次为一条连续奖项记录，允许责任人改名称，但当前最多展示一版。身份是 registration_id，不按自然人跨项目去重；专项奖有自己的连续记录。新授奖明确选择 placing / special，专项奖可选择本报名内的正式依据场次。已有最终名次不能通过换名称再发一项，须在赛事收尾核实原记录。
2. 原 source JSON 保留；新增 awardKind、awardRootKey、basisScope、basisResults（matchId/resultId/revision/status）和 previousHonorId。最终名次依赖项目内全部已建立、未取消场次的有效正式结果；专项奖依赖所选场次。更正、撤销及后续新增正式结果使相关奖项待复核，其他项目和不相关专项奖不受影响。只维护依赖和人工复核，不自动排出名次。
3. 旧中文明确名次（第 N 名、冠军、亚军、季军及已有名次后缀）按报名项目归并。旧 previousHonorId 链优先保留原奖项类型及祖先身份，即使改名后不再含名次词。无法确定属于名次的独立旧称号保留为专项奖，避免无依据地合并。兼容展示不删除原行，也不直接批量改旧库；责任人实际复核后，相关旧版转 revoked，新版绑定最新正式依据。
4. 复核按连续奖项展示参赛名单、项目、奖项类型、当前名称、真实代表行版本和正式赛果。待办计数与展示使用同一连续记录规则。允许核实已签发奖项；重新签发必须提交已查看依据的 fingerprint，证据变化、依据撤销或缺失、取消赛事、过期证明版本均拒绝。赛果更正、首次确认、授奖和重新签发共用 event-fixtures 事务锁；更新、撤销、签发及站内通知同事务办理。
5. 重新签发一项时，撤销该连续记录中仍在使用或待复核的旧版，并为原冻结获奖成员各生成一份新版。原依据、原名次、撤销/替换原因、前一证明编号保留；重复请求返回原回执。拒绝通过新请求键再次处理已替换版本。取消赛事不再重新签发，仍可撤销旧记录。
6. 参赛端默认只显示当前有效证明；history=true 返回本人全部证明，并区分 replaced / suspended / revoked。旧证明详情入口不能继续导出为有效证明；历史卡片保留原日期和原因，取消有效证明下载入口。不同项目和独立专项奖仍可同时有效。
7. 材料复用既有 MarkdownIt + DOMPurify 渲染组件，保留禁用 HTML、可执行标签、危险链接和远程图片的限制。已有稿、AI 生成稿、基础模板默认阅读预览；编辑正文显示原始 Markdown，预览不改写保存内容。标题、表格、列表、引用、代码块用共享文稿样式；手机端表格在文稿内滚动。

## 接口与边界

- POST /sports/b/competition/awards 新增可选 awardKind、basisMatchIds；旧调用可按明确名次文字识别类型。草稿或任意其他场次不能替代正式依据。
- GET /sports/proof-review/events/{eventId}?includeVerified=true 可查看已签发奖项；默认仅待复核。响应增加名单、项目、连续历史数量、依据场次与 basis_fingerprint。
- honor.resolve 仍只供责任人 UI 人工办理，Agent 不能确认真实赛果或奖项；reissue 的 basisFingerprint 必须绑定实际已查看的正式依据。接口保留确认回执和版本校验。
- GET /sports/c/proofs 默认当前有效；history=true 包含本人历史，status/current/reason 标识实际用途。本人或当前赛事组织的授权办赛人员才可读取有效证明详情。
- 复用 asp_honor.source JSON，不新增表或重写已应用迁移，不建立完整排名引擎和证书审批平台。跨表动作只用私有投影及纯规则工具，未引入表模块互依。
- 本轮隔离演练只使用合成账号、赛事和成绩，不代表真实赛事名次裁定、外部认证或全量业务验收。
