# ADR-022 Seedream平面体育主视觉

日期：2026-10-09。依据：用户明确要求通用体育平面设计、上方图片衔接下方背景和文字，并授权使用火山引擎Seedream 5.0 Flash。本决定接续ADR-021的场馆素材与待配置状态；不改变竞赛业务试运行范围。

## 供应商与图片

图像服务配置为火山方舟 images/generations，模型doubao-seedream-5-0-flash-260915，1536×1024，base64 JPEG，不加水印。Flash仅单图，不发送n、组图、流式或提示词fast选项。契约依据[官方图像接口](https://docs.volcengine.com/docs/ark/image-generation-api?lang=en)及[Seedream说明](https://docs.volcengine.com/docs/ark/seedream-4-0-5-0?lang=zh)，且已实际调用成功。凭据只在被Git忽略的本地.env配置，不进入前端、跟踪源码、文档或测试证据；独立于文案密钥。图像请求限制到HTTPS官方方舟主机，错误只返回分类和HTTP状态，不返回供应商原文。

提示词统一为二维体育平面设计、编辑插画、剪纸几何与轻印刷纹理，禁止场馆建筑主视觉、摄影及3D。明确运动项目仍优先于赛事名称暗示，未知项目使用抽象运动元素，通用体育活动可组合运动。不生成文字、费用、二维码或标志，不发送联系人、身份、报名材料。竞技、青少年、交流方向保留各自配色和运动语气。

通用素材sport-flat-seedream.jpg已实际生成并复制入项目，替代默认场馆图；画面为跑步、骑行、游泳等体育活动插画，不表示单项赛事包含这些项目。模型动态结果仍按对应赛事生成，原图保留只是历史素材，不再用于默认界面。

## 衔接、信息与复用

主体集中上部，图像下部提示渐变为#F6F0E8；画布另外叠加同色渐变，避免模型颜色不完全一致造成断带。文字完全位于图片下方的不透明暖白区，保留测量换行、动态高度、完整费用和独立二维码区域。导出PNG/PDF使用同一画布。没有叠加黑带、场馆标签或简单运动器材图标。

主视觉摘要加入flat-sports-v2提示版本，旧摄影结果标记过期；完整请求摘要同时包含图像模型，模型切换不会继续复用旧结果。同模型与同赛事描述的请求仍复用，不因前端换样式重复收费。保存、组织授权、同意、限频、同赛事锁及事务外调用继续沿ADR-021，无数据库迁移变更。

## 验证边界

真实供应商调用、工程模拟检查和普通角色业务验收分别记录。已成功生成一张通用样本并检查实际画面；不能据此宣称全部运动画面质量、真实普通角色保存/跨组织路径、生产部署或费用预算验收完成。后续事项继续在一期未完成事项追踪，不建设完整媒体或计费平台。

## 2026-10-09 文字区跟随主视觉底色

被取代：上文“画布另外叠加同色渐变到 #F6F0E8、文字区固定暖白”只保留为取色失败时的回退。预览、PNG 和 PDF 仍用同一画布。图片加载后，用约 40×24 的临时画布取主视觉底部约 15% 的最大颜色组，降低饱和度并调整明度，形成不透明文字背景；按亮度选择深色或浅色字，正文和强调色对比度至少 4.5:1。少量黑线和高饱和点不参与统计。图片下沿渐变到该底色，文字区不透出图片。二维码保持独立白底。取色失败、画布不可读或没有有效颜色时回到 #F6F0E8 暖白。不新增模型请求，不重复下载图片。现有绘图代次和卸载保护继续丢弃过期结果。

主视觉是否必须先有文案，以 [ADR-023](ADR-023-助手身份传递与报名草稿删除.md) 为准：现有 `promotion/visual` 可以在没有完整文案时保存图片。页面因此允许单独点击生成主视觉；本决定不修改图片保存实现。未配置图像服务时不发起请求。换风格、受众或关键词仍不自动调用生图。

## 2026-10-09 背景选择及先生图后文案

宣传材料新增自动选择已有图片、本赛事生成图片、赛事宣传图片、默认体育插画四种背景来源，标明当前实际来源；不存在的赛事图片选项不可选。背景切换只重画，不调用模型。指定生成图或赛事图片读取失败时提示并保留旧预览，不静默替换为默认材料。

用户显式勾选“先生成背景图片，再生成文案”后，先调用现有主视觉接口，选用返回的本赛事图片，沿既有取色/独立文字排版规则绘制，再调用文案接口填入内容。生图失败不继续文案请求，旧材料保留。未勾选仍只生成文案，保留独立生成主视觉按钮；供应商同意、限频、复用和权限不变。赛事预览与宣传抽屉显式允许遮罩点击关闭，并留出窄屏外部点击区域；不修改其他编辑弹窗的默认行为。
