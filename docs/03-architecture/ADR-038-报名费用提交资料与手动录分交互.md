# ADR-038：报名费用、提交资料与手动录分交互

日期：2026-10-12。状态：用户授权实施，本地隔离验证；正式业务验收边界沿用 ADR-011、ADR-029。

用户反馈：项目已设置收费，公开页面仍显示待公布；报名页面的文字、头像与侧栏不统一；审核缺少必要个人资料；只填写 A 侧的六行结果不能导入，希望点击选择胜方并在赛点后手动结束。

公开收费仍以有效费用策略为准。统一收款的 `event` 是有效收费模式，与旧 `offline`、`organizer_qr` 一并识别；免费必须有明确的零金额。公开页和报名页复用费用判断。报名草稿展示预计费用，正式提交时冻结应付；报价读取失败不推断免费，不产生付款义务。

审核资料只给当前赛事有管理权限的组织人员，经独立接口读取正式名单版本。展示提交时姓名、性别、出生日期、联系电话与本人填写的赛事采集项。采集项的标签和值与个人资料一起存入现有名单 JSON 快照，不新增表或迁移；后续个人档案或采集目录变化不改写该版本。旧版缺少采集项快照时明确提示，不用当前值冒充历史提交。普通成员卡与公开卡不增加其他人的联系方式或出生日期。

批量结果格式保持五列：`matchCode,slot,outcome,summary,games`。一侧即可自动补齐互补胜负，场次编号保留前导零；所有比分按 A:B。兼容旧双侧行及其 B 侧镜像比分；双侧相互冲突、重复同侧、未知场次、跨项目或改变已确认结果仍拒绝。支持换行及行尾反斜线。解析完成后在原单事务内写草稿，任一场失败整批回滚，请求键仍校验原内容。

录分编辑器提供胜方卡片、可直接填写及加减的当前比分、手动结束本局、修改/删除分局和手动结束比赛。结束本局更新编辑区局数；结束比赛建议胜方，用户仍须核对保存草稿。当前局未结束不能静默保存丢失计分。提示分可修改，默认 21 仅为用户界面辅助，不是专项竞赛规则；不自动判断两分优势、封顶、赛点、晋级或正式赛果。正式确认仍是独立人工动作，保留开赛时间、身份、事务和结果修订边界。

报名页的共用样式集中于 `plus-ui/src/assets/styles/registration-experience.scss`，删除该页重复的局部样式。统一头像 40px、正文 14px、卡片与侧栏间距；窄屏单列。录分弹窗正文滚动，底部保存保持可见，加减按钮保留触控空间。

实现与实际检查结果见 [本轮验证报告](../04-verification/报名与录分修复验证-20261012.md)。本轮不关闭全量一期验收，不代表真实银行款项、现场竞赛计分规则或所有附件已验收。
