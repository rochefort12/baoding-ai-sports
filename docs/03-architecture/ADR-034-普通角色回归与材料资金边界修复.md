# ADR-034：普通角色回归与材料、资金边界修复

日期：2026-10-11。依据：用户要求按现有一期功能，以羽毛球开展多账号、标准流程、多轮异常测试并修复。沿用 ADR-011、ADR-029；没有扩大一期范围。

## 办理边界

草稿允许保存未填完的本人资料；已填写的值仍校验格式、选项及权限。正式提交继续执行必填校验，冻结定义、本人值、名单、收费及独立付款义务。登录后的安全回跳包括已有的个人资料页面，仍拒绝外部地址和后台路径。

材料上传先持久提交任务与私有文件，再由模型经该运行环境的受控接口读取。Word、文本 PDF、扫描 PDF、图片保留实际来源覆盖、缺项与冲突。联系人、退改条款和项目费用分别保存候选；不同字段不要求重复同一段原文。项目必须关联当前已开放的比赛类型；有充分来源的整单价格可作为拟议收费，随任务版本、项目人数、名额与金额一起由主办方确认。模糊的每人价、加项价或冲突费用继续补问，不换算成未经确认的整单收费。

AI 创建收费规则不表示收款，也不代替收款渠道确认和赛事发布。政府审批、真实资金核实、正式结果与荣誉核实保留责任人办理。模型工具回执同时检查 HTTP、业务码及 JSON-RPC 错误，不能把业务拒绝写为成功。

报到和新建场次按当前付款义务及有效净收款检查，冲正后不足额不得新增参赛事实；按义务顺序加数据库锁，避免并发产生不一致。已有报到及结果保持历史可查，重复原请求不制造新事实。资格状态与资金状态继续分别维护。

请求键重复使用但内容改变会保存待核对异常。异常审计在原事务释放数据库锁后以独立事务保留，避免父事务持锁等待子事务、子事务又等父事务的互锁。人工处理仅限当前组织资金岗位，须提供说明、当前版本和请求键；精确重复返回原处理，不再次追加结案。异常处理不改变原付款、分配、退款、义务或资格事实。

历史资金仍放在报名详情。已正式提交后撤回的报名保留入口；未结异常不能因全额退款或重提而隐藏。原义务按实际名单提交版本区分，旧记录没有该版本时显示原创建时间，不猜测回填。切换历史义务可查询、退款和核对，不能以旧款替新义务缴费。

付款凭证上传动作通过纯文件契约保存私有图片，同时声明文件元数据的实际读写范围，继续绑定当前报名与本次付款义务。上传凭证不确认到账，不改变资格；只有报名资金管理人及授权本组织资金岗位可读取。队员收到的本人任务提供受控邀请详情入口，令已提交后的本人声明、状态和冻结名单可从任务列表返回，不因此获得报名管理或资金权限。

赛前可以报到、预排场次及准备录分草稿。首次确认正式赛果须已到赛事开始时间和该场已设置的开始时间；新授予赛事奖项须已到赛事开始时间。正常比赛收尾也须已经开赛，不能把未来赛事仅凭收尾状态写成比赛结束。取消赛事仍可在开赛前完成退款、投诉和取消收尾。已成功确认的原请求与已有证明保留历史可查，不因后来增加的门禁丢失。正在进行的赛事可以办理已完成场次的正式结果及奖项，无需等待整场赛事计划结束；条件同时由实际比赛事实和责任人确认约束。

已正式报名后重大比赛时间、地点、项目或费用说明不得通过下架绕过冻结；取消原赛另建。发布至少有一个已配置费用的项目。暂停主办方后兼容入口和统一入口都限制新增办赛，保留历史查询、退款、投诉及取消收尾。图片声明和本人采集必须在成员自己的任务内可阅读、填写及确认。

## 运行与证据

测试使用原隔离数据库和新前缀对象，先备份并独立恢复、核对全部公共表指纹。没有以 SQL 改业务数据、注入验证码或伪造银行到账取得成功。模拟资金、比赛、认证材料与真实模型/接口/UI操作分开标注。

运行包改用内容摘要目录，构建使用独立文件名，避免覆盖 JVM 正在读取的文件。首次构建引起的本机服务中断、旧包恢复、失败请求和之后修复复验全部保留。主站恢复到上一份可用包不等于原包精确恢复；最终安装和查询需另有证据。

共享表配置与当前模型目录对齐，仍由业务身份、组织、对象和用途判断授权；配置本身不授予全局查询。生成元数据经差异检查装配，手写业务保留。

当前落实状态以本轮回执及最终回归报告为准。真实短信、实际银行收退款、现场比赛和真实世界获奖凭据不能由隔离合成测试替代。
