# ADR-037 通用材料覆盖与可见处理进度

日期：2026-10-12。用户授权实施通用强Agent改进、聊天字体和气泡优化，以及简化流式反馈。承接ADR-029、030、032、036；不扩大业务写权限和一期正式业务边界。

通用材料与办赛资料复用本地解析器及原件存储。位置标签与原文正文分别用于展示、逐字校验，跨段声明仍要求真实连续正文；不能省略中间条款、重排或添加义务。Word长段按2000字分片保留末尾，通用入口读取全部位置；超过1000段、120000字或Word40图片时明确拒绝拆分，不静默截断。保留原文件及历史失败，旧任务升级解析时保留previousExtraction。

Word正文与表格单元格的嵌图按引用位置建立序号、SHA256和类型清单，不下载外部关系或执行文档内容。图片最多六张一批，由运行令牌或内部令牌校验原任务、文件归属与哈希后读取。通用Agent的视觉用量计入原根任务预算；转写逐图核验清单，模糊、二维码及不支持格式明确标记待人工核对。可见转写绑定文件/图片哈希保存，重试及原任务补充复用已完成结果，不重放成功业务动作。

资料建赛识别改为有限队列后台执行，提交尽快返回原任务编号，PROCESSING不能重复重试。仅产出候选，原人工修改保护和本人确认保存继续生效。失败返回的实际调用记录及具体字段保留；HTTP成功或资料转写不等于草稿完整，也不等于创建或发布赛事。

登录态SSE只发送已有可见任务快照，记录真实材料读取、图片核对、工具返回、字段校验、失败和待确认。每次读取核验本人或当前组织授权，运行令牌不进浏览器；断线只重新读取进度，不重复提交动作。展示和保存均不包含隐藏思考、reasoning_content、服务密钥或供应商原始错误。

共享字体规范：统一字体族，普通正文及控件14px、辅助说明12px、聊天正文16px和1.75行高。两端助手共用段落、列表、表格及处理记录规范，用户气泡靠右，助手回复靠左；桌面、手机均保留滚动、输入和原件核对入口。变更与真实验证分别记录，不用本ADR关闭未验收事项。

用户进一步要求资料图片提取、原句/元素点选、预填表单弹窗和连贯办赛交互。主办方助手移除“其他任务”浮窗分流，普通任务直接使用原通用Agent执行器、真实MCP权限及确认卡，在同一窗口接续；识别到办赛意图或无附加指令的规程上传时生成候选，不自动保存或发布。可继续向同一候选补充材料，已有人工字段、项目修改与手选封面保留；目录命名对不上时保留人工项目并明确提示核对。

“查看表单”打开独立对照弹窗：左侧为原文件段落、识别短项、图片与候选视觉文字，右侧是已填赛事与项目表单。支持选段、划选文字或识别短项填入、搜索原句以及点击图片选择封面。视觉分类只推荐poster/photo，table/qr保留资料用途；手选可更换，未经视觉读取的旧图片不推断用途。原件预览经当前组织会话及任务文件关系校验，图片为有界私有JPEG，不向浏览器发送运行密钥，也不提供永久公开地址。

表单保存仅更新asp_ai_task中的候选，按expectedVersion锁定版本；返回新版本后才可继续确认。确认沿用原项目、人数、名额、价格与声明校验，并从同一任务、原文件、图片序号及哈希派生event-banner，用已有文件契约绑定草稿；不会从客户端接受任意外部URL或跨任务文件。正式发布仍按原流程办理。

长文和引用采用来源位置ID：模型只选择支持字段的原句位置，服务端从已读取正文/候选视觉文字按原始顺序组装，避免重复生成长规程导致输出截断。通用Agent可返回source_quote引用请求，网关按授权材料ID填入原文后交给原展示契约；不存在、重复、不可读位置拒绝。短项仍提取实际短值并逐字核对依据。上传回执与页面提示标为系统观察，不作为用户最新目标进入模型历史；完整材料之后再次放入本轮实际用户请求，避免资料回执掩盖用户要求。

本轮覆盖范围为Word正文、原生表格单元格内Drawing嵌图、PDF文本层及缺少文字的扫描页、独立图片。Word页眉/页脚、VML/文本框及其他对象、带文本PDF页的独立配图、低质量扫描和规模负载仍未证明完整覆盖，不称任意文件全量理解。

完整引用优先在本轮最终结构中给出章节首末来源ID；若遗漏，只允许一次无工具的紧凑段落索引选择。索引只用于定位，最终正文仍从完整授权字典取出，不以段落开头代替正文。追加用量仍受原轮次／根任务限额约束。待人工确认的通用动作先处理原确认卡或退回修改，避免输入新消息意外另建任务。本轮反馈为可见阶段快照，回答完成后整体返回，不保存或展示隐藏思考。实际接受范围与未验格式见验证报告，不以ADR宣称通用能力无边界。
