### 6.2 另三种格式：每种独立核对

依次重复A01—A09，上传文本PDF、扫描PDF、规程图片，每次用新任务。向助手明确改名为 `本轮前缀-PDF识别草稿`、`本轮前缀-扫描识别草稿`、`本轮前缀-图片识别草稿`，仅保存草稿。

| 格式 | 人工特别核对 | 必须保留的证据 |
| --- | --- | --- |
| DOCX | 标题、段落、项目清单、正文声明均保留 | 文件名、识别依据、核对草稿、真实保存编号 |

### 6.3 缺项、冲突和识别失败

1. 上传“缺项.docx”，不要先在聊天里补齐；观察助手是否指出地点、截止、价格依据不足。
2. 回复具体值，要求更新草稿后再核对。若缺项未提问就建成可发布赛事，记录失败。
3. 上传“冲突.docx”；明确要求对照40元和60元两种原文。助手应请求主办方确定，不能自行选便宜或较新数字。
4. 本轮确认40元只是验收选择，须留确认说明；保存后仍只作独立草稿。
5. 识别失败时记录提示，使用“重试/重试识别”；先检查原任务是否已产生赛事，避免重复新建。
6. 模型不可用则保存进度，按第7节人工继续；记录“人工路线完成，真实模型环节未通过”，不冒充AI成功。
7. 不要为排查故障点击“放弃并删除资料”；该动作会放弃本任务资料。仅在确定不再需要的测试草稿上使用。

## 23. 撤回重提、超额、冲正与资金异常

### 23.2 超额收款与退多收

1. 对独立40元义务先核对确有模拟收款50，登记50；净额50，原应付40。
2. 由A在对应原收款办理多收10元的退款，填写依据。
3. 净额回40，退款10，仍符合收费资格；不是退40或修改原收费规则。
4. 尝试退超过原有效未退金额，应拒绝；不得部分写入一笔超额退款。

### 23.3 误记收款与冲正

1. 对独立40元义务登记一笔模拟40，并审核通过，记录当前资格及报到历史。
2. A在**该笔原收款**点“撤销此笔错误到账”，写清错误依据，确认。
3. 原收款保留为已撤销错误到账，净有效额下降；不是删除原行。
4. 尝试新报到或新建场次，应按当前资金复核拒绝；不能只因资格曾通过就继续参赛。
5. 有真实正确的新款时才补登记40，再核对后恢复可办理状态；重复冲正不应重复扣款。
6. 原款已经退款时不能随意再冲正，避免同时退钱又撤销造成资金双重扣减。

### 23.4 重复收款请求不一致与人工结案

这个异常需要同一请求编号但不同内容等真实触发条件；普通页面新开一次表单通常是**另一笔新登记**，不能将“再填不同金额”当作幂等冲突测试。

若受控异常样本出现“需要核对的收款记录”：

1. A打开该报名资金详情，查看“重复请求与原收款不一致”、关联原款、申报金额、待核对状态。
2. 点击“核对后结案”，填写“实际核对依据与处理说明”，说明原记录、本次差异、实账结果及责任人。
3. 点击“确认核对并结案”，刷新应已核对结案，只追加异常处理记录。
4. 原收款、退款、净额和报名资格不因此自动改变；有真实错款仍要另行冲正或退款。
5. 异常未结时即使余额看似0，也应阻止整场最终收尾。

如果页面无法自然产生该异常，由技术验收负责人按既有受控用例验证。人工人员记录“未在本轮触发”，不能注入接口、直接改库或假写一条异常来凑通过。

## 25. 外部世界荣誉认证与展示

世界季军、世界亚军、世界冠军是独立认证荣誉，**不靠成长积分自动升级**。传奇也是成长展示；不能把达到传奇当作已经拿到世界冠军。

演练资料必须显著写“模拟荣誉认证”，不得给虚构个人编造真实奥运冠军。真实申请需核实年份、正式赛事、运动项目、名次、本人归属和正式结果依据。例如展示文字里的年份和赛事必须真实对应，不能将用户举例的年份自动当作现实事实。

### 25.1 本人申请、上传私有证明、补正

1. 使用专门测试申请人本人登录（可用E），进入“成长与荣誉→荣誉认证”。
2. 点击“申请认证”，填写赛事年份、运动项目羽毛球、完整赛事名、名次冠军/亚军/季军及可补充的公开结果链接。
3. 点击“保存草稿”。**先保存，再上传证明**；没有当前保存对象不能上传。
4. 点击“上传证明”，选择模拟证明PDF或JPG/PNG/WebP，每份不超过5MB、最多8份。
5. 修改证明清单或字段后保存；核对当前状态“资料已保存”，点“提交核验”。
6. 应为待核验；不可在批准前佩戴“世界冠军”。
7. P工作登录→平台工作台“荣誉认证”，按状态找到本申请，打开“核验荣誉资料”，查看私有证明及本人归属。
8. 填核验说明写清缺少的材料，点击“要求补正”；申请人查看平台说明，修改、保存、再“提交核验”。不予通过时使用“不予通过”并给出依据，不用它替代本轮补正路线。

### 25.2 负责人核实与批准

1. P核对来源及本人，不由AI审核。填写核实后的年份、运动项目、完整赛事名称、名次、正式公布单位、正式结果依据（真实公开HTTPS来源）。
2. 按弹窗勾选已核实事实的确认，填核验说明，点击“通过认证”。
3. 若只有模拟材料，批准只在独立环境合成认证用例进行，说明明确“模拟事实”；正式环境无真实独立依据不能批准。
4. 本人刷新，已批准展示“已核验”；点“佩戴认证称号”，刷新应仍佩戴。
5. 点“允许公开展示”，同时在运动名片打开公开并保存；匿名窗口只看到公开荣誉标签，不看到私有证明/审核说明。
6. 点“关闭公开”，再次匿名查看不显示该荣誉；关闭整个运动名片后旧分享地址也受控。
7. 冠军、亚军、季军分别在独立申请里验证资源与头像框，不能用一个冠军记录硬切成另外两种名次。
8. P核对需要撤销的测试认证，填写依据，点击“撤销认证”；本人佩戴和公开标签同步失效，历史保存，成长积分不增减。

本轮模拟荣誉最终撤销或停止公开，避免被后续人员误当真实认证。若没有合法外部依据，记录真实认证阻塞，不用假URL凑真实认证通过。
