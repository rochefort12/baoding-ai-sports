# 首次IP发布与域名绑定

先用http://47.92.212.93提供HTTP入口，完成域名绑定及HTTPS后再正式使用。决定见[ADR-055](../03-architecture/ADR-055-首次IP访问与域名HTTPS切换.md)。三个依赖已经部署，本轮提供操作说明及可选监听地址配置，未自动发布网站。

## 1. ECS填写首次运行配置

在阿里云服务器终端或SSH登录后的Linux shell执行，原生Bash即可。

```bash
cd /opt/aisports/config
# 保留已经准备的随机密码；不覆盖以后已经填写过的应用配置。
if [ ! -f backend.env ]; then
  cp backend.env.pending backend.env
  chmod 600 backend.env
fi
sed -i 's|^PUBLIC_BASE_URL=.*|PUBLIC_BASE_URL=http://47.92.212.93|' backend.env
sed -i 's/^WEB_PORT=.*/WEB_PORT=80/' server.env
if grep -q '^WEB_BIND_IP=' server.env; then
  sed -i 's/^WEB_BIND_IP=.*/WEB_BIND_IP=0.0.0.0/' server.env
else
  printf 'WEB_BIND_IP=0.0.0.0\n' >>server.env
fi
chmod 600 backend.env server.env
```

这一步会改变公开地址配置；仅用于当前没有网站域名的首次访问验证。不打印配置内容，也不重新生成密码。模型/短信默认尚未配置，当前先验证页面就绪。数据库、Redis、MinIO管理端口继续只在内网/服务器回环可用。

## 2. 放行网站入口

阿里云ECS控制台 → 实例 → 安全组 → 入方向规则，允许TCP80。只开放网站入口，不把5432/6379/9000/9001管理端口开放到公网。云安全组未在本轮自动修改。服务器如另外启用了主机防火墙，也需允许对应网站端口。

## 3. Actions手动发布

打开[Deploy to Alibaba ECS](https://github.com/rochefort12/baoding-ai-sports/actions/workflows/deploy-ecs.yml)，点击Run workflow，分支main。填写已实际成功且包含本次WEB_BIND_IP配置的构建ID **38437805525**（提交f4c7708）。不要使用此前只支持回环地址的旧包。

填build_run_id，并勾选“已有数据库/文件已备份，或确认本次是无业务数据的首次部署”，然后运行。当前初始库asp业务表0，Flyway只有框架版本0标记；首次业务迁移由后端自动执行。这里不要求另行执行SQL，不触发依赖库重建。

## 4. 查看结果

Actions全部成功后，浏览器打开http://47.92.212.93/portal/login。匿名健康入口http://47.92.212.93/healthz应返回ok。HTTP阶段仅做页面/可达性验证，正式登录、业务办理与个人材料使用等HTTPS准备完成后进行。

服务器可检查：

```bash
docker ps --format '{{.Names}} {{.Status}} {{.Ports}}'
curl -fsS http://127.0.0.1/healthz
curl -fsS http://127.0.0.1/prod-api/auth/code >/dev/null
```

仅查看容器状态及匿名就绪结果，不公开完整日志或私有配置。成功发布应包括Java/Node/前端三个应用及已有三个依赖。若公网无法访问但本机healthz成功，优先核对TCP80安全组、主机防火墙及运营商/接入平台提示，不能仅凭域名绑定状态判定程序失败。

## 5. 绑定域名和配置HTTPS

DNS把网站域名指向47.92.212.93，完成接入平台要求的域名验证；需要特定校验文件/记录时按其实际要求配置。HTTPS代理和证书准备后，将PUBLIC_BASE_URL改成正式https网站地址，server.env恢复WEB_BIND_IP=127.0.0.1、WEB_PORT=8088，再手动发布并验证代理。TCP443及证书续期按实际入口完成。

文件域名另用于存储外部签名地址/HTTPS代理，当前MinIO仍私有。IP页面上线不等于上传签名、短信、模型、普通角色业务或容量验收通过。
