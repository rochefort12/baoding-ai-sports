## 运维命令

以下在阿里云服务器控制台或SSH后的Linux shell执行，使用原生工具。

```bash
docker compose --env-file /opt/aisports/config/dependencies.env \
  -f /opt/aisports/dependencies/compose.yml ps
docker stats --no-stream
```

需要重启时只操作这套依赖，容器的数据在独立持久卷中；有应用运行时应选择维护窗口。

```bash
docker compose --env-file /opt/aisports/config/dependencies.env \
  -f /opt/aisports/dependencies/compose.yml restart
docker compose --env-file /opt/aisports/config/dependencies.env \
  -f /opt/aisports/dependencies/compose.yml up -d --wait --wait-timeout 120
```

保留数据卷，不执行down -v/prune或凭据重新生成。不要把含密码的compose config解析输出、Docker环境检查或完整配置贴入日志/文档；配置语法用config --quiet核对。实际配置权限root0600，Redis文件0640、其父目录root0700。数据库/存储root账号及平台初始密码仅由服务器授权运维读取。

MinIO控制台通过SSH隧道访问。在本项目目录的本机PowerShell7执行：

```powershell
ssh -o StrictHostKeyChecking=yes -o UserKnownHostsFile=.local/ecs-connection/known_hosts -N -L 9001:127.0.0.1:9001 root@47.92.212.93
```

随后浏览器访问http://localhost:9001。存储管理员凭据位于服务器config/minio.env，业务应用使用独立受限账号；不将控制台或数据库映射公网。
