# ruoyi-sports-finance

2026-10-07 B端正式接入补充。

资金明细 API：GET /sports/b/fees/obligations/{id}/records。组织会话、payment 用途及租户校验后，以义务→报名→项目→赛事核对本组织归属，DTO 返回实际收款/分配/冲正和关联退款，不返回证据 JSON。新增 FundRecordsTest 与既有 FeeRulesTest 共 8 项单测通过，模拟依赖不是数据库验收。未改写原资金写操作。

界面与验证边界见[B端正式界面开发记录](../../../docs/05-ui/B端正式界面开发记录.md)。无模型、迁移或跨模块 Mapper 依赖变更。

## 2026-10-08 更新

确认接口接受每笔真实金额和必填实际时间，净有效收款减实际退款满足足额条件；资金写锁 PostgreSQL 义务行。原义务跨组织拒绝，幂等键仅重放同一事实。退款追加实际金额、时间、接收人与必要授权依据，可分次且不超原款；部分保留待办。撤销必须指定原 paymentId，已有退款禁止直接撤销。V019 提供退款接收人字段，旧记录不补造。接口及验收边界见 ADR-013，普通角色/并发/真实收退款仍须专项。
