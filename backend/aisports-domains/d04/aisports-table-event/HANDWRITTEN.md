# 赛事赛后收尾的时间边界

`EventClosureService` 继续按组织及 `organize` 岗位读取比赛、资金、问题和证明责任。正常赛事进入收尾/关闭还须已到公告开赛时间；数据库当前事务的真实时刻计算 `has_started`，不接受客户端时间。开赛前即使已有旧合成正式结果或收尾标记，查询也不能声称比赛已经结束。

取消赛事允许在原计划开赛前办理资金、投诉等收尾，原有未结义务、退款、异常和证明检查仍保留。已开赛后由责任人确认实际比赛结束，不以计划结束时间阻断合法逐场正式结果或提前完赛；系统的人工确认不证明真实现场事实。没有新增实际起止记录平台或改写计划时间。

`EventClosureTimeTest` 是 local 模拟边界：未来/缺时间正常赛事拒绝收尾且无写入，开始后仍须正式结果及其他待办完成，取消未来赛保持独立收尾。实际HTTP与自然时间流程另记，旧报告及合成结果保留原样。
