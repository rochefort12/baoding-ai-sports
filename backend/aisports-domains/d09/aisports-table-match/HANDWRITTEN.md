# 手工赛务的时间与历史边界

`CompetitionService` 的报到、赛前预排和结果草稿继续使用原权限、资格、付款、取消与结束限制。首次正式确认增加服务端时间门槛：赛事已到公告开始时间，存在场次排期时也已到该场次开始时间；不会要求等待整场赛事计划结束。缺少赛事开始时间不推测放行。

只有草稿转正式和新增本赛事荣誉使用新门槛。已有正式结果、原请求回执和已有荣誉保持可查询/重放，正式更正与撤销继续走独立版本流程，不回写旧事实。私有投影只增加读取数据库已有 `starts_at` / `scheduled_start`，不新增迁移、表工程依赖或现场时间平台。

`CompetitionStartWindowTest` 是 local 模拟边界：开赛/排期前拒绝且无结果、荣誉、执行回执或成长写入；进行中及结束后整理允许；既有正式历史不被新门槛误挡；精确起点、时区等价和起点前一瞬分别验证。实际未来赛拒绝与自然开赛流程由隔离HTTP另验，不能据单测声称真实比赛完成。
